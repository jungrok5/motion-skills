# Fonts

| file | family | license |
|---|---|---|
| `YeonSung.woff2` | BM YEONSUNG (배달의민족 연성) Regular, from Google Fonts — 2,436 Hangul syllables, jamo and basic Latin. The brush face words are written in (`InkBrush` in the page). | SIL OFL 1.1 — `OFL-YeonSung.txt` |

`world.js` loads it with a URL relative to the library, so pages work offline. For another script, or a smaller file for
a published page, subset an OFL brush font to the characters a world writes with `scripts/font.py` and keep its licence here.
