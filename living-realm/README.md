# living-realm

A place you can walk through in the browser, in a game-engine look, from **one HTML file with no assets**: every stone
wall, timber frame, tree, blade of grass, cloud and sound is generated by code when the page loads. A deferred WebGL 2
renderer (GPU-baked PBR materials, a computed atmosphere, cascaded soft shadows, ambient occlusion, fog with sun
shafts, temporal anti-aliasing that upsamples, bloom, a filmic grade) draws a world where the hour runs from dawn to
night, rain gathers and fills puddles, and winter brings snow and ice — as smooth changes. Walk with W A S D or the
arrow keys, look with the mouse or a thumb, or let the page stroll its own tour. Give the skill a topic and it designs
a new place in this style: the plan, the buildings from parts, the materials, the plants, the walk.

```bash
# the worked example: 은여울 마을 (Silverford), an MMORPG-style village
node living-realm/scripts/build.mjs  living-realm/examples/village        # → examples/village/index.html  (open it in a browser)
node living-realm/scripts/check.mjs  living-realm/examples/village        # loads clean · can be walked · every state reads
node living-realm/scripts/check.mjs  living-realm/examples/village --walk # only the walk, in one page load → out/walk.png (the plan from above)
node living-realm/scripts/render.mjs living-realm/examples/village --views           # → out/<view>.jpg
node living-realm/scripts/render.mjs living-realm/examples/village --sheet --scale .5   # every view × day, dusk, night, rain, snow
node living-realm/scripts/render.mjs living-realm/examples/village --tour 12 --scale .5 # twelve stills along the tour, as its camera looks
node living-realm/scripts/render.mjs living-realm/examples/village --phone             # → out/phone.jpg: what a phone shows (its canvas, tier and scale)

# a realm of your own
node living-realm/scripts/new-realm.mjs my-realm            # from the starter (Tarn Cabin); write BRIEF.md first
node living-realm/scripts/build.mjs my-realm && node living-realm/scripts/check.mjs my-realm
```

On the page: **W A S D / arrows** walk · **Q E / ← →** turn · mouse or touch looks (left thumb walks, right thumb looks) · a gamepad's sticks walk and look · **Shift** runs · **1–4** dawn, day,
dusk, night · **5–7** clear, rain, winter · **T** the automatic round · **C** the tour · **G** quality · **M** sound ·
**P** numbers. Options: `?q=low|medium|high|ultra`, `?tod=19.5`, `?wx=rain`, `?tour=0`.

Requirements: Node 18+ with Playwright Chromium, ffmpeg (sheets and films). The page needs WebGL 2 and wants a GPU;
without one, stills render on the CPU at 10–60 s each. three.js r170 is vendored (MIT, `vendor/LICENSE`).
