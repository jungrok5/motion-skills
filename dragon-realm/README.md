# dragon-realm

A cinematic short film of a legendary long-bodied creature — a dragon, an imugi, a sea serpent, a wyrm — in a living
landscape, played live in the browser from **one HTML file**: pure three.js, no images, models, fonts or sound files.
Rock, water, clouds, trees, buildings, scales and the whole score are generated by code when the page loads, and every
frame is a pure function of film time, so the same page loops live and renders to a 1080p MP4 with sound. Give it a
topic (a culture, a place, a creature and what happens to it) and it designs the land, the light, the creature, the
stage, the shots and the music.

```bash
cd dragon-realm
node scripts/check.mjs examples/cheongryong                      # check OK: deterministic, every shot reads, the body is possible
node scripts/render.mjs examples/cheongryong --cast --scale .5   # out/cast.jpg: the dragon from every side
node scripts/render.mjs examples/cheongryong --sheet --scale .33 # out/sheet.jpg: every shot at its start, middle, end
node scripts/score.mjs examples/cheongryong                      # out/score.wav + loudness per section
node scripts/render.mjs examples/cheongryong                     # out/film.mp4 (1920 × 1080, 30 fps, 84 s, with the score)
# the live film: open examples/cheongryong/index.html (built by any of the above) — click for sound, space pauses

node scripts/new-film.mjs ~/my-film                              # a new film folder from the starter (Tarn Wyrm, 14 s)
```

Requirements: Node 18+ with Playwright Chromium, ffmpeg. No npm install, no GPU, no API keys (on four CPU cores a 1080p
frame of the example takes 3–6 s, the whole film about two and a half hours; the live page wants a real GPU).

Source: made from https://github.com/ChetasLua/crimson-loong (赤龍 · Crimson Loong by Chetaslua — a 90 s dragon film in
pure three.js with no assets), shared at https://x.com/chetaslua/status/2121176151234330707?a=fPtJuQnZ47fP-u87Nkc&s=19.
That repository carries no licence, so no code was taken from it: its methods were studied and this engine was written
from scratch (`references/SOURCE.md`). Worked example: `examples/cheongryong` 「청룡 · 여의주」 — a Korean telling: an
imugi in a mountain lake under five granite peaks takes the yeouiju in a storm and rises as the Blue Dragon at sunrise.
Starting film: `starter/` (Tarn Wyrm). three.js r170 is MIT (`vendor/LICENSE`).
