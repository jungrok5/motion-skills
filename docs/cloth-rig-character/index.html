cloth-rig-character

주제 하나를 주면 머리가 크고 몸이 작은 3D 캐릭터를 블렌더에서 부품별로 만들고 옷을 차례로 입힌 뒤, 몸뿐 아니라 치마 · 리본 · 목도리 · 머리채에도 뼈를 넣어 대기와 눈 깜박임 → 돌아서기 → 걷기를 한 동작씩 만듭니다. 돌아설 때 치마가 퍼지고 리본이 늦게 따라오며, 회색 바닥 · 고정 카메라 · 구석의 뒷모습 설정화로 검토합니다. 보고 만든 원본: Claude Code Studio(@ClaudeCode_love)의 X 게시물 (「服に骨を入れるかが9割」, 블렌더 + Claude로 만든 캐릭터의 작업 순서), 그 작가의 원 게시물 rewind(@rewind02).

  • 블렌더 · bpy
  • 3D 캐릭터 리깅
  • 옷에 뼈 · 2차 동작
  • glTF + three.js
  • MP4

작업 흐름

입력
주제 한 줄 (선택: 앞 · 옆 · 뒤 설정화)
브리프
입는 순서대로 적은 부품, 흔들릴 옷과 뼈 줄 수, 동작 목록, 검토 기록 — character.json
만들기
블록아웃 → 부품 → 겹쳐 입기 → 몸 뼈 + 옷 뼈 줄 → 대기 · 돌아서기 · 걷기를 한 동작씩 → 스프링으로 치마 · 리본의 따라오는 움직임을 키로 굽기
검사
스키닝, 앞뒤좌우, 관절 범위(무릎은 뒤로 · 팔꿈치는 앞으로), 발 고정, 진행 방향, 옷 움직임, 결정성 — 11개 + 턴어라운드 · 캐스트 시트(양쪽 방향)
출력
.blend, 애니메이션 든 .glb + three.js 검토 플레이어, 검토 MP4(Cycles), 스틸 · 시트
python3 -m venv ~/.venv-bpy
~/.venv-bpy/bin/pip install bpy
S=path/to/cloth-rig-character; PY=~/.venv-bpy/bin/python
$PY $S/scripts/hero.py new my-hero --from hanbok-girl
cd my-hero          # BRIEF.md → character.json
$PY $S/scripts/hero.py check
$PY $S/scripts/hero.py sheet
$PY $S/scripts/hero.py stills --clip walk
$PY $S/scripts/hero.py render
$PY $S/scripts/hero.py player

요구 사항: 블렌더의 파이썬(pip install bpy 또는 블렌더 본체), ffmpeg. GPU 없이 동작합니다. 블렌더 MCP로 한 단계씩 실행하는 방법과 단계별 순서는 SKILL.md에 있습니다.

예제 examples/hanbok-girl · 7.7초 · 대기 → 한 바퀴 → 돌아서기 → 걷기

샘플

원본에 없는 주제 두 가지로 만든 캐릭터입니다. 스틸은 블렌더 Cycles로 렌더한 검토 화면이고, 카드를 누르면 같은 캐릭터의 .glb가 three.js 검토 플레이어에서 재생됩니다.

설빔 소녀 examples/hanbok-girl · 새 주제로 만든 예제

색동 소매 저고리, 가슴에서 묶은 진분홍 치마(뼈 12줄 × 4마디), 앞고름, 댕기 땋은머리, 프로젝트에서 새로 만든 노리개 부품.

대기 · 눈 깜박임숨쉬기와 무게 이동가슴이 오르내리고 엉덩이가 좌우로 옮겨 가며, 0.9초에 눈을 깜박입니다.
한 바퀴 · 1.7초치마가 피어나는 회전치마 뼈 줄이 늦게 따라오며 바깥으로 퍼지고, 옆으로 꼬이거나 안으로 접히는 각도는 제한해 다리에 감기지 않습니다.
걷기 · 2.8초고름과 댕기가 흔들리는 걸음디딘 발은 미끄러지지 않고, 엉덩이가 오르내리며 치맛단이 다리를 따라 흔들립니다.

비옷 아이 starter · 시작 예제

노란 비옷(밑단 뼈 8줄), 빨강 · 흰 줄무늬 목도리(꼬리 2줄 × 5마디), 파란 장화. 라이브러리 부품만으로 만든 시작 캐릭터입니다.

대기 · 눈 깜박임비 오는 날 기다리기짧은 단발, 큰 눈, 볼터치. 몸은 3.8등신입니다.
돌아서기 · 1.3초머리가 먼저, 목도리는 나중에반대쪽으로 살짝 감았다가 돌고, 작은 걸음 두 번으로 방향을 바꿉니다.
걷기 · 2.8초빠른 짧은 걸음보폭 0.44, 두 걸음 0.72초. 고무 비옷이라 치마보다 단단하게 흔들립니다.

몸 검사 hero.py sheet

앞 · 3/4 · 옆 · 뒤를 양쪽 방향으로 렌더한 턴어라운드와, 동작 포즈를 양쪽 옆에서 본 캐스트 시트입니다. 뒷모습은 검토 영상 구석의 설정화가 됩니다.

턴어라운드설빔 소녀, 여섯 방향고름과 노리개는 앞, 땋은머리와 댕기는 뒤에 있는지 봅니다.
캐스트 시트동작 포즈, 양쪽 옆무릎은 뒤로, 팔꿈치는 앞으로만 접히는지 봅니다. 자동 검사가 모든 프레임을 같은 기준으로 잽니다.
턴어라운드비옷 아이, 여섯 방향단추와 목도리는 앞, 후드는 뒤에 있습니다.

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 Claude Code Studio(@ClaudeCode_love)가 X에 정리한 작업 순서와, 그 작가 rewind(@rewind02)가 올린 4초 영상(검은 꽃무늬 원피스에 흰 챙 넓은 모자를 쓴 소녀가 회색 바닥에서 대기 → 돌아서기 → 걷기를 하고, 구석에 뒷모습 설정화가 있는 검토 화면)입니다. 이 스킬은 그 방법(부품 → 겹쳐 입기 → 옷에 뼈 → 한 동작씩 → 따라오는 움직임 → 검토 화면)과 검토 화면의 모양만 가져오고, 원본의 소녀는 쓰지 않았습니다. 두 캐릭터의 디자인과 코드는 모두 이 레포의 것입니다.
