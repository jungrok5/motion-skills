storybook-portrait

주제(직업 · 사람 · 순간 · 감정)를 주면 그 주제에 맞는 인물을 새로 설계해 요즘 그림책 스타일의 초상으로 자바스크립트가 직접 그립니다. 무광 과슈 피부, 어두운 머리에 색 줄이 섞인 마른 붓 결과 삐져나온 잔머리, 옆을 보는 작은 눈동자의 크고 둥근 눈, 큰 머리 아래쪽에 모인 작은 이목구비, 빨간 볼, 긴 목, 종이 결이 비치는 크레용 무늬 옷, 떨리는 가는 잉크 선을 흰 종이 위에 획 하나씩 올립니다. 이미지 파일은 하나도 쓰지 않습니다. 다 그린 뒤에는 숨 쉬고, 불규칙하게 깜빡이고, 눈이 먼저 움직이면 고개가 반대쪽으로 살짝 움츠렸다가 따라가 지나쳤다 돌아오며, 머리카락과 귀걸이가 늦게 따라옵니다. 보고 만든 원본: Vamsi Batchu(@vamsibatchuk)의 X 게시물 (@Artedeingenio의 참고 그림 한 장으로 순수 코드만 써서 여러 주제를 그린 방법).

  • 그림책 일러스트
  • 과슈 · 크레용 · 잉크
  • 주제 → 새 인물
  • 살아 있는 초상
  • PNG · MP4 · 라이브

작업 흐름

입력
주제 한 줄(예: 양봉하는 할머니, 새벽 빵집 견습생, 비 오는 날 일부러 나가는 아이)
브리프
한 줄 정의와 피할 것, 인물(나이 · 성격 · 주제를 한눈에 알리는 이야기 소품 · 무게 · 대기 동작), 얼굴 수치, 머리 모양과 색 줄, 옷 무늬 한 가지와 부딪는 색 한 쌍, 같은 재료로 그린 소품, 팔레트 5–7색, 시선 · 고개 비트와 큰 동작
그리기
과슈 피부 → 눈 · 코 · 볼 → 머리카락 덩어리 → 어두운 마른 붓 결 → 띠로 모인 색 줄 → 귀 · 귀걸이 → 잔머리 → 크레용 옷과 무늬 → 소품, 획마다 붓 방향으로 칠해지는 과정
확인
캐스트 시트(좌우 회전 · 표정 · 좌우 눈길 동작), 결정성, 종이 여백 · 잉크 · 팔레트 · 평평한 면 없음, 방향 규칙(코 · 가까운 귀 · 가슴 앞이 같은 쪽), 숨 · 불규칙한 깜빡임 · 눈이 먼저 · 예비 동작 · 지나침 · 머리카락 늦게, 고정된 아래쪽 가장자리, 스틸 채점 기준 10개
출력
1080×1350 또는 2160×2700 PNG, 그리는 과정 단계 스틸, 캐스트 시트, 그려진 뒤 살아 움직이는 MP4, 라이브 페이지
node storybook-portrait/scripts/new-portrait.mjs my-portrait
node storybook-portrait/scripts/render.mjs my-portrait/piece.html --cast
node storybook-portrait/scripts/check.mjs my-portrait/piece.html
node storybook-portrait/scripts/render.mjs my-portrait/piece.html --scale 2
node storybook-portrait/scripts/render.mjs my-portrait/piece.html --stages 6
node storybook-portrait/scripts/render.mjs my-portrait/piece.html --film

요구 사항: Node 18+와 Playwright Chromium, MP4 · 단계 스틸에만 ffmpeg. 네트워크 · npm 설치 · GPU가 필요 없습니다(초상 한 장이 0.3–0.6초, 검사 전체가 몇 초, 17.5초 MP4가 약 40초). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/beekeeper · 7.5초 동안 그려진 뒤 살아 움직임 · 누르면 다시

샘플

원본 그림에 없는 주제 세 개를 브리프부터 새로 설계해 그린 인물입니다. 카드를 누르면 새 탭에서 브라우저가 같은 획을 직접 그리는 라이브 페이지나 캐스트 시트가 열립니다.

양봉가 할머니 예제 · 무거운 몸 · 곱슬머리 · 안경 · 벌

옥상에서 벌을 치는 할머니가 떠나지 않는 벌 한 마리를 눈으로 좇습니다. 회색 곱슬머리는 이 주제를 위해 새로 만든 머리 모양(마른 붓 나선 약 95개, 아래는 어둡게 위는 밝게)이고, 동그란 안경 · 꿀 디퍼 브로치 · 벌은 같은 재료로 그린 소품입니다. 시선 비트는 벌이 나는 경로에서 0.55초마다 읽어 오고, 고개는 벌이 한쪽 끝에 갔을 때만 천천히 따라갑니다.

완성벌을 좇는 눈과슈 피부, 곱슬 나선, 갈색 잉크 안경테
그리는 과정획이 올라가는 순서피부 → 얼굴 → 머리 → 옷 → 소품
캐스트 시트좌우로 돌려 보기코 · 가까운 귀 · 가슴 앞이 한 방향, 가슴은 고개의 절반
살아 있는 동안눈이 먼저, 고개는 나중벌의 경로에서 읽은 시선 비트, 고개를 돌릴 때 깜빡임

새벽 빵집 견습생 예제 · 올림머리 · 앞치마 · 밀가루 · 하품

새벽 4시 50분 빵집의 막내가 하품을 참지 못합니다. 이야기 소품은 밀가루(볼에 묻은 자국, 코끝, 앞치마의 손자국, 오븐 빛 속에 떠오르는 가루)이고, 큰 동작은 하품입니다. 숨을 깊게 들이쉬며 고개가 뒤로 넘어가고, 입이 천천히 벌어졌다가 놓이고, 고개를 좌우로 털어 냅니다.

완성밀가루 묻은 얼굴빗어 넘긴 마른 붓 결과 나선 번, 주황 색 줄
큰 동작하품모으기(깊은 숨) → 천천히 벌어짐 → 멈춤 → 놓고 털어 냄
캐스트 시트왼쪽으로 눈길눈 먼저 · 예비 동작 · 돌기 · 지나침 · 자리 잡기
그리는 과정앞치마는 마지막에크레용 결 위로 종이가 비침

비 오는 날 시작 그림 · 가벼운 몸 · 짧은 머리 · 우비

new-portrait.mjs가 복사하는 시작 그림입니다. 비가 오면 일부러 나가 빗방울을 세는 아이를, 노란 우비와 목 뒤로 젖힌 모자, 비스듬히 떨어지는 파란 색연필 빗줄기로 그렸습니다. 원본 그림(긴 흑청색 단발, 줄무늬 카디건)과 겹치지 않게 고른 주제입니다.

완성빗방울을 세는 아이갈색 머리에 황토색 줄, 주근깨, 선으로 그린 코
그리는 과정시작 그림우비 모자는 몸에 붙은 뒤쪽 층
캐스트 시트표정 다섯눈썹 기울기 · 들림, 입꼬리, 벌린 입, 눈꺼풀

실제 작품

이 레포에서 만든 스킬입니다. Vamsi Batchu(@vamsibatchuk)가 X에 공개한 방법이 출발점입니다. @Artedeingenio의 참고 그림 한 장을 모델에 주고, 외부 파일이나 스킬 없이 순수 자바스크립트 · p5.js · 파이썬 코드만으로 여러 주제의 그림을 그리게 했고, 어떤 스타일에도 대체로 통한다고 했습니다. 이 스킬은 그 방법과 그림체의 문법(과슈 피부, 색 줄이 섞인 마른 붓 머리, 크레용 옷, 떨리는 잉크 선, 옆을 보는 큰 눈)을 가져와 어떤 주제든 새 인물로 그릴 수 있게 만들었습니다. 참고 그림과 그 인물은 쓰지 않았고, 시작 그림과 예제의 인물은 모두 이 레포의 것입니다. 그림체의 원작자는 @Artedeingenio입니다.
