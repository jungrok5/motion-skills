lit-room

주제를 주면 밤의 작은 방 하나를 3D로 짓고, 책상 위 모니터에 그 주제의 웹페이지를 띄웁니다. 페이지는 클릭 · 선택 · 입력이 되는 실제 HTML이고, 그 화면의 빛이 방의 조명입니다. 분홍 페이지는 책상을 분홍으로 물들이고, 페이지 위 빛을 왼쪽으로 끌면 방의 왼쪽이 밝아지며, 방을 끌어 둘러보는 동안에도 화면은 원근 그대로 눌립니다. 원본: Felix Rieseberg의 「Lit Room」 데모(HTML-in-Canvas 데모 페이지, X 게시물)을 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보이고, 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas
  • 화면이 곧 조명
  • 절차적 3D 방
  • WebGL2 조명
  • 코드 전용

작업 흐름

입력
주제 하나(배의 해도대, 해 질 녘 교실, 문 닫은 카페 카운터, 아이 방, 라디오 부스 …)
브리프
방과 시간 · 앉는 사람 · 소품 8–14개(주제용 새 소품 2–4개) · 색과 재질 · 방의 램프 · 창밖, 그리고 화면 속 페이지(탭 · 끌 수 있는 빛 · 입력하는 한 줄 · 프리셋과 그 색이 방에 주는 빛)를 적은 BRIEF.md
방
데이터로 쓴 방(ROOM): 구멍 난 벽 · 바닥 · 천장 · 창밖 하늘이나 바다, 상자 · 원기둥 · 회전체 · 관으로 만든 소품, 캔버스 2D로 그린 그림 · 해도 · 러그
빛
페이지 밉맵 → 8×5 칸의 면광원(정점마다), 화면에서 나오는 부드러운 그림자, 광택면의 화면 반사, 방 램프, 미리 구운 AO, 페이지 밝기를 따라가는 노출
출력
폴더 하나의 라이브 페이지(index.html + lib/), 네트워크 없이 file:// · 아티팩트에서 동작, 검사 숫자와 스틸
node scripts/new-page.mjs ../my-lit-room
node scripts/check.mjs ../my-lit-room/index.html
node scripts/still.mjs ../my-lit-room/index.html --out ../my-lit-room/out --act "idle;close;mood:neon,tab:mood"
node scripts/check.mjs examples/night-watch/index.html

요구 사항: Node + Playwright Chromium(스크립트가 HTML-in-Canvas 플래그를 켭니다). 라이브로 보려면 Chrome · Edge 157 이상이나 Claude 데스크톱 앱. 단계별 순서는 SKILL.md에 있습니다.

샘플

예제 「Night Watch」와 시작 템플릿 「Quiet Hours」를 HTML-in-Canvas를 켠 Chromium에서 찍은 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

「Night Watch」 배의 해도대 · 새벽 2시 40분

작은 범선 선실의 해도대입니다. 화면은 당직 페이지이고 현등 세 개(좌현 빨강 · 우현 초록 · 마스트 흰빛)를 끌면 선실의 빛이 바뀝니다. 나침반 · 말린 해도 · 밧줄 타래 · 매단 랜턴은 이 주제를 위해 페이지 안에서 만든 소품입니다. 원본에 없는 주제로 브리프부터 끝까지 만든 예제입니다.

예제 · 기본 시점당직 중인 해도대랜턴 · 나침반 · 말린 해도 · 현창 너머 달빛 바다
예제 · 현등 끌기빨강은 왼쪽, 초록은 오른쪽랜턴을 끄고 현등을 양 끝으로, 책상이 두 색으로
예제 · 바다 프리셋새벽밝은 페이지가 탁자와 벽을 장밋빛으로
예제 · 더블클릭화면 가까이원근 그대로 입력되는 침로 한 줄
예제 · 둘러보기밧줄 타래와 현창방을 끌어 돌아보면 선실의 다른 쪽

「Quiet Hours」 시작 템플릿 · 해 질 녘 글 쓰는 책상

새 작품의 출발점입니다. 빛 세 개를 끌고 한 줄을 고쳐 쓰는 페이지, 메모, 네 가지 분위기, 책상 램프 스위치가 있습니다.

템플릿 · 기본 시점글 쓰는 책상창 · 커튼 · 선반 · 화분 · 키보드
템플릿 · 분위기네온페이지 색이 바뀌면 방의 빛도
템플릿 · 분위기종이흰 페이지는 조명, 눈처럼 노출이 따라감

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 Felix Rieseberg가 Claude 데스크톱 앱에 HTML-in-Canvas를 켜며 공개한 데모 열다섯 개 중 「Lit Room」입니다. 저녁의 방에서 모니터 속 페이지의 빛이 방을 물들이는 형식과 기법만 가져오고, 엔진(실행 중 페이지에서 계산하는 빛) · 소품 · 페이지 · 문구는 모두 이 레포의 것입니다.
