logo-construction

주제나 브랜드 하나를 주면 격자 위에 새 기하학 로고를 설계하고, 그 로고가 만들어지는 과정을 세로 영상으로 보여 줍니다. 회색 러프 스케치 위에 커서가 같은 기울기의 사선과 수평선을 긋고 복사해 옮기고, 확대해서 원을 끌어 그린 뒤, 셰이프 빌더로 칸을 하나씩 채우고 가이드를 지우고 모서리를 둥글립니다. 마지막에는 완성된 로고와 목업(플리스 · 물병 · 명함 · 간판 · 토트백)을 보여 줍니다. 로고의 모든 변은 가이드 위에, 모든 꼭짓점은 가이드 두 개가 만나는 자리에 있습니다. 스케치 · 화면 도구 · 목업까지 모두 코드로 그리고, 클릭 소리까지 합성한 1080×1920 MP4와 라이브 페이지로 냅니다. 보고 만든 원본: The Dr. Logos(@TheDoctorLogos)의 X 게시물 (디자이너 graphicdesignpark의 무스 로고 제작 과정 영상).

  • 2D 캔버스 · 코드 전용
  • 로고 작도 · 9:16
  • 격자 규칙 검사
  • 코드로 그린 목업 5종

작업 흐름

입력
주제나 브랜드 하나(이름, 하는 일, 누구를 위한 것인지)
브리프
로고가 그리는 대상과 이유, 24 px에서도 읽혀야 할 특징, 바라보는 방향, 기울기, 사선 · 수평선 · 자유선 · 원과 묶음, 칸과 둥글기, 서명 · 워드마크 · 잉크색, 브랜드에 맞는 목업 2–4개, 단계별 시간을 적은 BRIEF.md
설계
mark.js의 격자(같은 기울기의 사선, 평행선 묶음, 대칭 쌍, 원)와 가이드 교차점으로만 정한 칸, 그리드 시트(가이드 이름 · 꼭짓점 · 256/128/48/24 px · 좌우 반전)
확인
모든 변이 가이드 위인지, 48 px에서 구멍이 막히지 않는지, 눈이 바라보는 쪽에 있는지, 발이 바닥선에 닿는지, 커서가 손처럼 움직이고 화면 밖으로 나가지 않는지, 스케치가 로고의 복사본이 아닌지, 목업 대비, 결정성
출력
30fps 1080×1920 MP4(합성 클릭 · 채움 · 정렬 · 컷 소리와 잔잔한 패드), 라이브 페이지
cd logo-construction/examples/lighthouse
node ../../scripts/render.mjs index.html --mark
node ../../scripts/render.mjs index.html --acts --scale .5
node ../../scripts/check.mjs index.html
node ../../scripts/render.mjs index.html
node ../../scripts/new-piece.mjs ../../../my-mark

요구 사항: Node + Playwright Chromium, ffmpeg. 네트워크와 GPU가 필요 없습니다(45초 영상을 CPU 4코어로 약 30초). 단계별 순서는 SKILL.md에 있습니다.

샘플

브리프로 설계한 두 로고, 커피 로스터의 여우 「Ember Fox」와 페리 회사의 등대 「North Pier」의 단계별 장면입니다. 카드를 누르면 새 탭에서 그 순간부터 영상이 재생되고, 브라우저가 가이드와 로고와 목업을 직접 그립니다.

Ember Fox 1080×1920 · 43초 · 시작 작품

새벽에 볶는 커피 로스터를 위한, 걸음을 내딛는 여우입니다. 몸 전체가 14° 기울기를 공유합니다. 목덜미 사선은 목 뒤이자 귀 뒤이고, 가슴 사선은 몸 앞이자 앞다리 앞입니다. 다리 선은 한 번 긋고 복사해서 옮깁니다. 꼬리 끝은 사선 두 개 사이의 틈으로 흰 끝을 나타냅니다.

North Pier 1080×1920 · 44초 · 동물이 아닌 주제로 만든 예제

항구 페리 회사를 위한 줄무늬 등대입니다. 한 방향 기울기 대신 6°로 마주 기운 두 벽으로 탑을 좁힙니다. 층을 나누는 수평선은 일부러 고르지 않게 놓은 뒤 정렬 패널로 같은 간격으로 분배합니다. 빛줄기는 좌우 대칭인 평행 띠이고, 물결은 같은 원 다섯 개를 복사해 띠에서 오려 냅니다.

스케치 · 1초회색 러프 스케치줄무늬 등대와 빛줄기, 물결

실제 작품

이 레포에서 만든 스킬입니다. The Dr. Logos(@TheDoctorLogos)가 X에 올린 41.5초 세로 영상(디자이너 graphicdesignpark가 회색 스케치 위에 같은 기울기의 선과 원으로 무스 로고를 작도하고 셰이프 빌더로 채운 뒤, 플리스 · 물병 · 배낭 목업으로 보여 주는 영상)이 출발점입니다. 이 스킬은 그 형식(만드는 순서, 단계마다의 모양과 움직임, 모든 변이 가이드 위에 있다는 규칙)만 가져옵니다. 원본의 무스, 서명, 목업 사진은 쓰지 않았고, 두 로고와 장면은 모두 이 레포의 것입니다.
