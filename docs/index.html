AI 에이전트가 재사용할 수 있는 모션그래픽 스킬 모음입니다. 아래 샘플은 영상 파일이 아니라, 지금 이 브라우저에서 코드로 그려지고 있습니다.

canvas-film

장면마다 다른 화풍으로, HTML Canvas만으로 그리는 시네마틱 영상. 같은 장면 파일로 MP4 녹화(가로·세로)와 웹 실시간 재생을 모두 하고, 언어 파일만 더하면 다국어가 됩니다.

  • 장면 하네스 — seek(t)로 어느 프레임이든 정확히 그림
  • 녹화 — Playwright + ffmpeg, 1920×1080 / 1080×1920
  • 사운드 — ElevenLabs 음악·효과음 큐 믹스
  • 웹 플레이어 — 영상 없이 13분 ≈ 10MB
  • 다국어 — 번역 파일 · 폰트 교체 · RTL
