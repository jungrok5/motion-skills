설치

스킬 폴더를 프로젝트의 .claude/skills/에 복사하거나 심볼릭 링크로 연결합니다. 아래 명령은 canvas-film을 연결하는 예입니다. 연결한 뒤 만들 영상을 설명하면 에이전트가 맞는 스킬을 골라 씁니다. 에이전트에게 그 폴더의 SKILL.md를 직접 읽게 해도 됩니다.

git clone https://github.com/jungrok5/motion-skills
mkdir -p .claude/skills && ln -s "$PWD/motion-skills/canvas-film" .claude/skills/

스킬 추가

새 스킬은 대개 다른 프로젝트 레포에서 실제 작품을 만들며 다듬은 뒤 이 레포로 옮겨 옵니다. 폴더 구조, 출처 표기, LESSONS.md, 샘플 페이지를 만드는 순서는 CONTRIBUTING.md에 있습니다. 이 페이지의 카드 목록은 skills.json에서 만듭니다.
