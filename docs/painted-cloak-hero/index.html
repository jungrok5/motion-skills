painted-cloak-hero

주제 하나를 주면 블렌더에서 7등신 3D 영웅을 옷 한 벌씩 따로 만들고, 망토 · 모자 · 옷을 붓 자국이 보이는 손 그림 질감으로 칠합니다. 망토는 몸과 함께 움직이지 않고 몇 프레임 늦게 따라오며, 대기 · 걷기 · 달리기는 끊김 없는 루프로 만들고 동작마다 이름과 프레임 카운터를 띄운 검토 영상과 어긋난 곳 목록을 냅니다. 보고 만든 원본: 작가 rewind(@rewind02)의 X 게시물 (밀짚모자와 붓 자국 파란 망토의 영웅, 블렌더 + Claude).

  • 블렌더 · bpy
  • 손 그림 붓 자국 질감
  • 몇 프레임 늦게 따라오는 망토
  • 루프 사이클 · 동작별 검토
  • glTF + three.js

작업 흐름

입력
주제 한 줄 (선택: 앞 · 뒤 설정화 두 장)
브리프
입는 순서대로 적은 옷, 붓 자국 색(어두운 색 → 밝은 색), 망토의 무게와 늦게 따라오는 프레임 수, 동작마다 자세 · 예비 동작 · 회복, 검토 기록 — character.json
만들기
설정화 앞 · 뒤 → 블록아웃 → 바지 · 셔츠 · 장화 · 모자를 따로 만든 메시 → 붓 자국 질감(UV 위에 미터 단위로 그린 획, 망토 밑단과 밀짚 챙은 올이 풀린 가장자리) → 몸 뼈 + 망토 뼈 줄 → 대기 · 걷기 · 달리기 루프와 돌아서기를 한 동작씩
망토
마디마다 몸이 lag × i / n 프레임 전에 있던 자리를 쫓아감 — 어깨는 지금, 밑단은 몇 프레임 늦게 · 팔의 흔들림도 같은 만큼 늦게 · 부드러운 한계로 루프가 정확히 반복
검사
관절 범위, 움직이는 바닥 위에서 발 고정, 망토가 늦는 프레임 수(1–8), 밑단이 뒤로 끌리는지, 다리와의 간격, 루프 닫힘, 숨쉬는 대기, 돌아서기 예비 동작, 붓 자국 대비, 결정성 — 14개 → REVIEW.md 어긋난 곳 목록
출력
.blend, 동작별 애니메이션이 든 .glb + three.js 검토 플레이어, 동작마다 검토 MP4(Cycles), 설정화 · 턴어라운드 · 캐스트 시트
python3.13 -m venv ~/.venv-bpy
~/.venv-bpy/bin/pip install bpy
S=path/to/painted-cloak-hero; PY=~/.venv-bpy/bin/python
$PY $S/scripts/hero.py new my-hero --from snow-postman
cd my-hero          # BRIEF.md → character.json
$PY $S/scripts/hero.py check     # → out/REVIEW.md
$PY $S/scripts/hero.py concept
$PY $S/scripts/hero.py sheet
$PY $S/scripts/hero.py review
$PY $S/scripts/hero.py player

요구 사항: 블렌더의 파이썬(pip install bpy 또는 블렌더 본체), ffmpeg. GPU 없이 동작합니다. 블렌더 MCP로 한 단계씩 실행하는 방법은 references/BLENDER-MCP.md에 있습니다.

예제 examples/snow-postman · 대기 · 걷기 · 달리기 · 돌아서기 · 끌어서 카메라 돌리기

샘플

원본에 없는 주제 두 가지로 만든 영웅입니다. 스틸은 블렌더 Cycles로 렌더한 검토 화면이고, 카드를 누르면 같은 영웅의 .glb가 three.js 검토 플레이어에서 재생됩니다.

눈 고개 우편배달부 examples/snow-postman · 새 주제로 만든 예제

진홍 망토(뼈 9줄 × 4마디, 5프레임 늦게), 남색 제복과 놋쇠 단추, 겨자색 털모자, 프로젝트에서 새로 만든 가죽 가방 부품. 달리기를 더했습니다.

달리기 · 0.67초 루프뒤로 흐르는 망토밑단이 몸보다 늦게 따라오며 뒤로 끌리고, 두 발이 모두 뜨는 순간이 있습니다. 루프는 0.1 cm 안에서 닫힙니다.
돌아서기 · 150°몸이 멈춘 뒤에도 도는 자락반대쪽으로 살짝 감았다가 두 걸음으로 돌고, 엉덩이가 자리를 잡는 동안 망토는 계속 흔들립니다.
대기 · 3.5초 루프붓 자국으로 칠한 옷가슴이 오르내리고 무게가 옮겨 가며 두 번 깜박입니다. 망토의 색 네 가지는 어두운 색부터 차례로 칠했습니다.

비 오는 날 뱃사공 starter · 시작 예제

삿갓, 이끼색 망토(4프레임 늦게), 크림색 셔츠, 올리브색 바지, 갈색 장화. 라이브러리 부품만으로 만든 시작 영웅입니다.

걷기 · 검토 영상원본과 같은 검토 화면평평한 바닥, 고정된 빛, 구석의 설정화, 동작 이름과 프레임 카운터. 카메라는 앞에서 옆으로 돌고 바닥은 걸음만큼 흘러갑니다.
걷기 · 1초 루프몇 프레임 늦은 자락디딘 발은 흘러가는 바닥에 붙어 있고, 망토 밑단은 측정해 보면 몸보다 3.4프레임 늦게 움직입니다.
돌아서기 · 180°삿갓과 망토밀짚 삿갓은 둘레를 따라 짧은 획으로 칠하고 가장자리 올을 풀었습니다.

설정화와 몸 검사 hero.py concept · hero.py sheet

원본의 1단계처럼 망토까지 그린 앞 · 뒤 설정화를 만들고(사용자가 준 그림이 있으면 그것을 씀), 동작 포즈를 양쪽 옆에서 본 캐스트 시트로 무릎 · 팔꿈치 방향을 봅니다.

설정화앞 · 뒤 두 장뒷모습은 검토 영상 오른쪽 위에 고정됩니다.
캐스트 시트동작 포즈, 양쪽 옆무릎은 뒤로, 팔꿈치는 앞으로만 접히는지 봅니다. 자동 검사가 모든 동작의 모든 프레임을 같은 기준으로 잽니다.
턴어라운드뱃사공, 여섯 방향걸쇠와 셔츠는 앞, 망토는 뒤에 있는지 봅니다.

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 rewind(@rewind02)가 X에 올린 4초 영상(찢어진 밀짚모자와 붓 자국 파란 망토를 두른 영웅이 서 있다가 걷고, 카메라가 앞에서 옆으로 돌며, 구석에 뒷모습 설정화와 "HERO / ANIMATION REVIEW" 글씨가 있는 검토 화면)과 여덟 단계 작업 순서입니다. 이 스킬은 그 방법(설정화 → 블록아웃 → 옷 메시 → 붓 자국 → 몸 뼈 + 망토 뼈 → 망토가 늦게 따라오는 대기 · 걷기 → 검토 화면 → 동작별 렌더와 어긋난 곳 목록)과 검토 화면의 모양만 가져오고, 원본의 영웅은 쓰지 않았습니다. 두 영웅의 디자인과 코드는 모두 이 레포의 것입니다. 바로 앞 단계의 방법(옷에 뼈 넣기)은 cloth-rig-character에 있습니다.
