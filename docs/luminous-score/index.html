luminous-score

곡 하나를 주면 어둡고 안개 낀 방에 놓인 악보 위로 카메라가 낮게 미끄러지고, 음이 울리는 순간 그 음표가 성부의 색으로 빛나 종이에 빛을 드리웠다가 잔광으로 사라지는 영상을 만듭니다. 오선 · 성부 색 · 방 · 샷을 곡에 맞게 설계하고, 소리도 같은 음표에서 합성해 화면과 소리가 한 시계로 갑니다. 보고 만든 원본: 🎼🌺Music Love♥️의 X 게시물 (비발디 「겨울」을 악보가 빛나는 영상으로 시각화).

  • three.js 악보
  • 음표 조명
  • 기보 엔진
  • 합성 사운드
  • MP4 · 라이브 페이지

작업 흐름

입력
곡 하나(퍼블릭 도메인 곡의 마디 범위, MIDI 파일, 영상용으로 새로 쓴 곡). 레퍼런스 영상이 있으면 그 스틸
브리프
어느 마디를 어디서 가져오는지와 권리, 한 줄 느낌, 오선과 성부(주인공 빛), 성부마다의 색과 이유, 종이 · 안개 · 빛 · 눈이나 먼지, 템포 지도, 음악 사건마다의 샷, 성부마다의 소리를 적은 BRIEF.md
악보
텍스트 성부(마디 검사 포함), 반복 패턴은 P.add 루프, MIDI는 midi2score.mjs. 끝없는 한 줄 총보로 기보: 음자리표 · 조표 · 박자표 · 빔 · 쉼표 · 임시표 · 붙임줄 · 셈여림
확인
마디 · 음역 · 색 검사, 울리는 음과 주인공 성부가 화면 안에 있는지, 음이 울릴 때 무언가 빛나는지, 검거나 하얗게 날아간 프레임, 결정성, 소리의 무음 · NaN · 늦은 시작
출력
30fps 1920×1080 MP4와 WAV, 브라우저에서 바로 재생되고 ♪ 버튼으로 소리를 합성하는 라이브 페이지
cd luminous-score/examples/candle-prelude
node ../../scripts/check.mjs index.html
node ../../scripts/render.mjs index.html --sheet --scale .5
node ../../scripts/render.mjs index.html --preview
node ../../scripts/render.mjs index.html
node ../../scripts/new-piece.mjs ~/my-piece
node ../../scripts/midi2score.mjs piece.mid

요구 사항: Node + Playwright Chromium, ffmpeg. GPU · npm 설치 · API 키가 필요 없습니다(CPU WebGL에서 960×540 한 프레임 약 0.23초, 38.8초 템플릿 미리보기를 워커 4개로 약 4분). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/candle-prelude · 바흐 C장조 전주곡 1–19마디 · 75.3초 · ♪ 버튼으로 소리

샘플

원본 영상에 없는 곡으로 브리프부터 새로 설계한 예제의 장면, 원본의 겨울 분위기로 쓴 시작 템플릿, 검토용 이미지입니다. 카드를 누르면 그 순간이 라이브 페이지에서 멈춘 채 열립니다.

「Prelude in C」 촛불 아래 바흐 BWV 846 · 1–19마디 · 75.3초

피아노 한 대, 오선 두 줄, 세 성부의 빛: 오른손 아르페지오는 촛불 금색, 왼손의 테너는 장밋빛, 베이스는 호박색. 따뜻한 양피지 · 먼지 · 책상 위에서 읽는 높은 카메라

시작 · 2.8초도드라진 제목책상 위 악보를 내려다보다가 제목에 내려앉음
2마디첫 화음들읽는 각도의 카메라, 주인공 빛은 아르페지오
6마디시스템을 따라 낮게패턴이 자리 잡으면 오선이 멀리 모이는 낮은 샷
10마디아르페지오 가까이오른손만 담는 샷, 빛나는 음표 옆에 아직 꺼진 음표
13마디반음씩 내려가는 베이스왼손에 맞춘 측면 샷, 지나온 음을 돌아봄
19마디 · 끝마지막 C 화음리타르단도에 맞춰 올라가 내려다봄, 잔광이 사라짐

「First Snow」 시작 템플릿 독주 바이올린 · 현 · 쳄발로 · 14마디 · 38.8초

원본의 겨울 분위기로 새로 쓴 짧은 알레그로입니다. 성부가 하나씩 들어오며 빛이 늘고, 독주의 빨간 빛이 아르페지오를 그립니다. 새 곡은 여기서 시작해 곡에 맞게 바꿉니다

1마디첼로 혼자아래 두 오선에 맞춘 낮은 샷
5마디독주 등장빨간 독주 빛이 16분음표 아르페지오로 들어옴
10마디모두, 포르테총보 전체를 담는 높은 샷
13마디유니즌 질주빠른 음이 빛의 꼬리를 남김
14마디길게 끄는 마지막 화음페르마타를 템포 단계로, 지나온 질주를 돌아봄

검토 기보 · 시트

샷을 쓰기 전에 악보를 위에서 내려다보고, 샷마다 시작 · 정착 순간을 한 장에 모아 검토 기준으로 채점합니다

pitch 89°위에서 본 기보음자리 · 빔 · 붙임줄 · 한 오선의 두 성부 확인
render.mjs --sheet샷 시트샷마다 시작과 정착 순간을 스틸 검토 기준으로 채점
