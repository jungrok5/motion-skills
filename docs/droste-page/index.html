droste-page

주제 하나를 주면 자기 자신의 그림이 끝없이 들어 있는 살아 있는 웹페이지를 만듭니다. 진짜 DOM 페이지 한 장에 액자 같은 창이 있고, 그 창에 페이지 전체가 다시 그려지며, 그 안에 또 그려집니다(드로스테 효과). 스크롤하면 사본 속으로 끝없이 빨려 들어가고, 진짜 슬라이더로 에셔의 나선처럼 감을 수 있습니다. 모든 사본이 같은 라이브 페이지라서 글자를 고치면 모든 사본이 한꺼번에 바뀌고, 어느 깊이에 그려진 버튼을 눌러도 그 버튼이 눌립니다. 사본마다 번호와 시간대의 빛이 다릅니다. 원본: Felix Rieseberg의 「Droste」 데모(HTML-in-Canvas 데모 페이지, X 게시물)을 보고 만들었습니다. 코드 · 그림 · 소리는 모두 새로 썼습니다. 라이브 데모는 Chrome / Edge 157 이상이나 Claude 데스크톱 앱에서 움직이고, 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas · WebGL2
  • 등각 드로스테 사상
  • 끝없는 줌 · 에셔 나선
  • 모든 사본이 라이브
  • 합성 사운드 · 코드 전용

작업 흐름

입력
주제 하나(타일 벽의 그림, 자기 사진이 놓인 책장, 자기 화면을 띄운 휴대폰, 시리얼 상자 뒷면 …)
브리프
자기 그림을 품을 표면 · 창의 위치와 배율 S · 액자 · 고칠 수 있는 한 줄 · 누를 것 2–8개와 바뀌는 것 · 번호가 놓일 자리 · 감기 조절기 이름 · 영역별 재질 · 사본마다 바뀌는 빛 3–6개 · 소리
페이지
보통 HTML/CSS로 짠 한 장의 페이지(가로 · 세로 배치, 폴백 포함)와 Droste.create({...}) 설정 한 개. 셰이더가 재질(타일 유약 · 회벽 · 나뭇결 · 인쇄 망점 · 금속)과 액자 몰딩 · 빛 · 그림자 · 번호를 더함
확인
공통 라이브 페이지 검사, 모든 버튼의 역사상, 한 단계 깊은 사본에서의 실제 클릭, 두 사본에 동시에 반영되는 타이핑, 낙하와 정착 시간, 감기와 정수 바퀴 고정, 조용할 때 선명한 업로드, 밝기, 스틸 채점
출력
네트워크 없이 file://과 Claude 아티팩트에서 도는 폴더 하나(index.html + lib/), 스틸
cd droste-page
node scripts/check.mjs examples/cereal-box/index.html
node scripts/check.mjs templates/index.html
node scripts/still.mjs examples/cereal-box/index.html --out out --poses "rest;fall=-0.3,wind=0;fall=0.5,wind=2"
node scripts/new-page.mjs ../my-page
node scripts/check.mjs ../my-page/index.html

요구 사항: Node + Playwright Chromium(스크립트가 HTML-in-Canvas 플래그를 켬). 단계별 순서는 SKILL.md에 있습니다.

샘플

예제 「Spiral Crunch」와 시작 템플릿을 여러 감기 · 낙하 자세에서 찍은 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

「Spiral Crunch」 시리얼 상자 뒷면

시리얼 상자 뒷면에 그 상자 뒷면의 그림이 인쇄되어 있습니다. 상표를 고치고, 퍼즐의 고리를 깨물고, 상자를 비틀면 나선을 따라 들어간 모든 상자가 함께 바뀝니다. 원본에 없는 주제로 브리프부터 끝까지 만든 예제입니다.

한 바퀴 · 쉬는 자세상자 속의 상자열리며 빨려 든 뒤 멈추는 자세. 사본마다 번호 1, 2, 3
감기 0평평한 중첩그림 속의 그림. 사본마다 부엌의 빛이 바뀜
감기 2두 겹 나선한 바퀴 돌 때마다 두 사본씩 깊어지는 나선
감기 1.5접힌 이음매정수 바퀴 사이에서 닫히지 않는 자리를 마분지 주름으로

갤러리 벽 시작 템플릿

회벽에 걸린 금박 액자 속 그림이 그 벽 자체입니다. 작은 그림을 누르면 모든 사본에서 다시 칠해지고, 황동 명판의 번호와 시간대가 사본마다 다릅니다.

한 바퀴 · 쉬는 자세그림 속의 방액자 · 램프 · 명판 · 작은 그림 · 벽 라벨 · 판자 벽
감기 0정면의 액자창살 빛 · 회벽 질감 · 액자 그림자 · 명판 번호 3
감기 2에셔의 화랑나선을 따라 노을 · 밤 · 새벽으로 바뀌는 빛
