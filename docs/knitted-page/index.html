knitted-page

주제를 주면 실제 웹페이지를 털실로 뜬 니트로 만듭니다. 코마다 아래 페이지의 색 하나를 받고, 늘어진 실을 당기면 한 줄씩 풀려 실타래 더미가 되었다가 바늘이 다시 떠 올립니다. 페이지는 그대로 살아 있어 제목을 고쳐 쓰면 바뀐 코만 다시 떠지고, 버튼과 라디오는 그려진 자리에서 눌립니다. 원본: Felix Rieseberg의 「Knitted Page」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보이고, 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas
  • 털실 니트
  • 실 당겨 풀기
  • 살아 있는 웹페이지
  • 코드 전용

작업 흐름

입력
주제 하나 (겨울 장터 포스터, 할머니의 레시피 카드, 스키 산장 메뉴, 축구팀 머플러 페이지)
브리프
페이지와 컨트롤, 실 색과 게이지, 무늬, 테이블, 바늘, 풀면 드러나는 것
페이지
코 단위로 짠 실제 HTML, 큰 글자, 세로 화면 배치
검사
공통 HTML-in-Canvas 검사, 다시 뜨기 · 실 당기기 · 풀기 · 드러난 층 클릭 · 안전망 수치
출력
폴더 하나짜리 라이브 페이지(index.html + lib/), 스틸
node scripts/check.mjs examples/apple-cake/index.html
node scripts/still.mjs examples/apple-cake/index.html --out out --act pull --u 0.35
node scripts/new-page.mjs ../my-knitted-page
node scripts/check.mjs ../my-knitted-page/index.html

요구 사항: Node + Playwright Chromium(검사와 스틸은 HTML-in-Canvas 플래그를 켜고 실행). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/apple-cake · 할머니의 사과 케이크 레시피 · 실을 당겨 보세요

샘플

템플릿(겨울 장터 포스터)과 새 주제로 만든 예제(할머니의 레시피)를 여러 상태에서 찍은 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

할머니의 사과 케이크 examples/apple-cake

브리프부터 새로 설계한 예제입니다. 면사 게이지, 사과 무늬, 깅엄 식탁보, 스틸 바늘, 풀면 드러나는 할머니의 비밀 쪽지.

예제 · 쉬는 상태떠 놓은 레시피인분 버튼과 오븐 타이머가 살아 있는 페이지
예제 · 다시 뜨기스틸 바늘실타래 더미에서 실이 바늘로 이어짐
예제 · 모두 풀림할머니의 비밀드러난 쪽지도 실제 HTML, 버튼으로 다시 뜨기

겨울 장터 포스터 templates/index.html

스타일의 기본 예시입니다. 페어아일 띠, 여덟 꼭지 별, 배색 3가지, 아래에 숨은 추첨권.
