latte-art-pour

주제를 주면 위에서 내려다본 잔에 스팀 우유를 부어 라떼아트가 그려지는 짧은 영상을 만듭니다. 그림은 칠하지 않고, 우유가 흐르는 표면 시뮬레이션이 그립니다: 낮게 흔들면 로제타 잎이, 높게 끊어 밀어 넣으면 튤립 단이, 가늘게 그으면 줄기가 생깁니다. 원본: @ujae_의 Threads 게시물(뉴질랜드의 모션 그래픽 디자이너가 만든 라떼아트 시뮬레이터를 소개한 글과 두 영상)을 보고 만들었습니다.

  • 붓는 대로 그려지는 표면 시뮬레이션
  • 하트 · 로제타 · 튤립 · 에칭
  • 음료 · 잔 · 테이블 · 그림을 주제마다 설계
  • 코드만 · 붓는 소리 합성
  • 1080×1920 MP4 · 직접 부어 보는 페이지

작업 흐름

입력
잔 하나의 주제 (카페의 계절 메뉴, 결혼식, 아침 바, 브랜드, 한 사람 …)
브리프
그림과 고른 이유, 붓는 방향, 음료 · 잔 · 테이블 색, 동작 표(채우기 · 내리기 · 흔들기 · 밀어 넣기 · 긋기 · 에칭)와 단계 문구
붓기
동작 표가 피처의 높이 · 흐름 · 위치를 움직이고, 표면 시뮬레이션이 거품을 밀어 그림을 만듦 (칠하는 그림 없음)
검사
check.mjs: 결정성 · 잔 안쪽 붓기 · 피처의 이징과 예비 동작 · 그림의 넓이와 윤곽 · 끝난 뒤 정지 · 대비 · 글자 크기와 겹침 · 소리, 스틸 검토
출력
라이브 HTML 페이지(?play=1로 직접 붓기)와 붓는 소리가 든 1080×1920 MP4
node latte-art-pour/scripts/new-film.mjs my-cup --title "제목"
node latte-art-pour/scripts/check.mjs my-cup
node latte-art-pour/scripts/render.mjs my-cup --shots
node latte-art-pour/scripts/render.mjs my-cup   # → out/my-cup.mp4

요구 사항: Node + Playwright Chromium (Canvas 2D, GPU 필요 없음), ffmpeg. 단계별 순서는 SKILL.md에 있습니다.

예제 「벚꽃 찻집의 말차 튤립」 · 네 단 튤립 · 17초

샘플

예제와 스타터의 단계별 순간입니다. 카드를 누르면 라이브 페이지가 그 순간에 멈춘 채 열립니다(클릭 · 스페이스로 재생).

벚꽃 찻집의 말차 튤립 새 주제로 만든 예제 · 위로 붓기 · 17초

원본에 없는 주제입니다. 봄 한정 말차 라떼를 슬레이트색 도자기 잔에, 피처를 잔 아래에 두고 위로 부어 꽃이 위를 향하게 했습니다. 높게 끊어 갈색 틈을 내고 뒤에서 한 단씩 밀어 넣어 네 단을 쌓은 뒤 줄기를 긋습니다.

장면 · 1초빈 잔과 제목높이 부어 바탕을 채우기 전, 슬레이트 도자기 잔의 말차
단계 2 · 6초첫 송이낮게 내린 물줄기 앞에서 거품이 솟아 첫 송이가 핌
단계 3 · 9초뒤에서 밀어 넣기높게 끊어 갈색 틈을 낸 뒤 다음 단을 밀어 넣음
단계 4 · 12초줄기 긋기들어 올린 가는 물줄기를 단 사이로 끌어 줄기를 세움
끝 · 17초완성된 잔피처가 빠지고 제목과 설명이 뜨며 천천히 다가감

Rosetta 스타터 · 에스프레소 · 16초

가장 기본이 되는 잔입니다. 제자리에서 흔들어 잎을 부채꼴로 쌓고, 흔들며 뒤로 물린 뒤, 한 번에 그어 잎을 줄기로 묶습니다.

단계 3 · 8초흔들며 쌓기제자리에서 흔들어 잎을 부채꼴로 쌓음
단계 4 · 11초가르기가는 물줄기로 잎 사이를 갈라 줄기를 냄
끝 · 16초Rosetta줄기로 묶인 잎, 제목과 설명

실제 작품

이 레포에서 만든 스킬입니다. 원본 게시물의 영상에서 붓는 원리(높이 · 흔들기 · 밀어 넣기 · 긋기)를 읽고, 시뮬레이터의 코드 · 화면 · 이름은 가져오지 않고 표면 모델과 영상을 처음부터 만들었습니다.
