# Demo assets

Live versions of the nine sample videos (no sound). Each `<id>/index.html` is the original video page with fonts swapped to
the files below; `?f=p` or `?o=v` shows the portrait layout. The tax-accountant pages use a fictional person
("한서윤 세무회계", phone 02-000-0000, illustrated portrait `avatar.svg`) in place of the real client.
