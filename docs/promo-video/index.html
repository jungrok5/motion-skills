promo-video

회사 사이트나 블로그를 읽고 15–40초 홍보 영상을 가로와 세로 MP4로 만듭니다. ElevenLabs 내레이션 · 효과음 · 배경음악을 넣고, 영상마다 다시 만들 수 있는 원샷 프롬프트를 남깁니다.

  • 16:9 · 9:16
  • MP4
  • 내레이션
  • 배경음악
  • 원샷 프롬프트

작업 흐름

입력
회사 사이트 · 블로그 · 프로필에서 확인한 사실만 모은 정리표
제안
추천 스타일 한 개와 이유, 다른 스타일 3–4개, 장면별 스토리보드
영상
영상마다 HTML 파일 한 개. render(t)로 프레임을 그리고 30fps로 녹화
사운드
내레이션 한 번 녹음을 문장별로 잘라 장면에 배치, 효과음, 직접 작곡하거나 ElevenLabs로 만든 배경음악, 덕킹 −10dB · −14 LUFS
출력
MP4 1920×1080 · 1080×1920, 영상별 원샷 프롬프트(영상 제작 · ElevenLabs 분리)
cd promo-video
node scripts/render.mjs examples/minimal/index.html --stills 2.5,14.5
node scripts/render.mjs examples/minimal/index.html
python3 scripts/mix.py examples/minimal/mix.json --mux

요구 사항: Node + Playwright Chromium, ffmpeg, Python 3 (numpy), 새 음성 · 음악은 ElevenLabs 커넥터. 단계별 순서는 SKILL.md에 있습니다.

예제 examples/minimal · 30초 · 소리 없음

샘플

실제 고객 두 곳을 위해 만든 영상 9편입니다. 세무사 영상 5편은 가상 인물(이름 · 연락처 · 일러스트 초상)로 바꾼 샘플입니다. 카드를 누르면 브라우저에서 그리는 영상이 소리 없이 재생됩니다 (화면을 누르면 처음부터, ?f=p는 세로).

세무사 홍보 5편 · 가상 인물로 바꾼 샘플

같은 사무소를 다섯 가지 화풍으로 그렸습니다. 고객과 채널에 맞춰 고르도록 제안한 시안입니다.

프리미엄 키네틱 · 30초5월에만 찾는 세무사? 남색과 금색, 단어별 등장, 금색 와이프 전환
종이 콜라주 · 20초영수증 한 장이 곧 세금 12fps 스톱모션, 찢긴 종이 · 테이프 · 도장
채팅 화면 · 24초바로 묻는 세무사 질문 · 입력 중 · 답변 세 번, 알림 카드로 마무리
잡지형 큰 숫자 · 21초16년, 숫자 뒤에서 그리드 선, 숫자 롤링, 파란 패널 와이프
화이트보드 · 37초1분 세금 노트 손글씨 선 그리기, 형광펜, 지우개 전환

해외 구매대행 홍보 4편 · fortimoveglobal.com

회사 소개 페이지 하나로 만든 네 가지 버전입니다. 미니멀과 팝 숏폼은 스킬의 예제로 들어 있습니다.

미니멀 흑백 + 초록 · 30초이거 어디서 팔아요? UI 목업, 숫자 올라가는 견적서, 원형 아이리스 전환
지구본 여정 · 25초지구 반대편에서도 캔버스 지구본, 레이더 탐색, 비행 궤적
팝 숏폼 · 18.75초사진 한 장이면, 끝. 128bpm, 모든 컷과 효과음을 박자에 맞춤
언박싱 스토리 · 25초택배가 오기까지 책상 위 소품, 폴라로이드 검수 사진, 3D로 열리는 상자
