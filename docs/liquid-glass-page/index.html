liquid-glass-page

주제를 주면 그 주제의 실제 웹페이지(렌즈 사양서, 스파 가격표, 비 오는 날의 시, 수족관 입장권, 꿀 시음 카드 …)를 만들고, 그 위에 주제에 맞게 설계한 액체를 얹어 그립니다. 물결은 감쇠 파동 방정식으로, 방울은 메타볼 필드로 계산해 페이지를 스넬의 법칙과 분산으로 굴절시키고, 깊이만큼 물들이고, 그림자와 집광을 드리우고, 작은 방을 비춥니다. 포인터는 젖은 손끝이 되고, 클릭하면 물결이 일고, 큰 방울은 끌어서 돋보기로 씁니다. 그 아래의 글자는 선택되고 입력칸은 타이핑되며 버튼은 돋보기 너머로도 눌립니다. 원본: Felix Rieseberg의 "Liquid Glass" 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 코드는 모두 새로 썼습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보입니다. 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas · WebGL2
  • 굴절 · 분산 · 메타볼 방울
  • 살아 있는 페이지
  • 주제마다 액체 설계
  • 코드 전용

작업 흐름

입력
주제 하나(꿀 시음 카드, 카메라 렌즈 사양서, 스파 가격표, 비 오는 날의 시, 수족관 입장권 …)
브리프
페이지가 어떤 문서인지 · 살아 있는 입력칸과 버튼 · 페이지 위 조작판 · 젖지 않을 글자 · 액체(굴절률 · 분산 · 색 · 농도 · 점도 · 방울 크기 · 흔적) · 날씨(비 · 바람 · 흘러내림) · 빛 · 동사 이름을 적은 BRIEF.md
페이지
주제의 실제 HTML과 CSS, Liquid.start({...}), 조작판을 물리적 원인(온도 → 점도처럼)에 연결하는 코드
확인
스틸 채점(읽힘 · 액체다움 · 돋보기 · 구성 · 밝은 종이와 어두운 종이) · 물결이 일고 3초 안에 잦아드는지 · 손끝 흔적 · 큰 방울 끌기와 멈춤 · 돋보기 너머 클릭 · 선택 · 결정적 스틸
출력
index.html + lib/ 한 폴더(file:// · Claude 아티팩트에서 동작, 네트워크 없음), 스틸 PNG
cd liquid-glass-page
node scripts/check.mjs examples/honey-tasting/index.html
node scripts/still.mjs examples/honey-tasting/index.html --out out --at 4 --act drag --to 'td.notes'
node scripts/new-page.mjs ../my-liquid-page
node scripts/check.mjs ../my-liquid-page/index.html

요구 사항: Node + Playwright Chromium(스크립트가 --enable-blink-features=CanvasDrawElement로 기능을 켭니다). 네트워크와 npm install이 필요 없습니다. 단계별 순서는 SKILL.md에 있습니다.

예제 examples/honey-tasting · 꿀 · 흘러내림 · 온도로 점도 조절

샘플

템플릿(물을 얹은 시 카드)과 예제(꿀을 얹은 시음 카드)를 기능을 켠 Chromium에서 찍은 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

꿀 시음 카드 examples/honey-tasting

양봉장의 시음 카드 위에 히스 꿀. 위에서 천천히 흘러내린 꿀 리본, 온도로 바뀌는 점도, 꿀 색 네 가지.

예제 · 큰 방울시음 노트 위의 돋보기끌어 온 큰 꿀방울 아래 확대된 살아 있는 글자
예제 · Drizzle꿀 뿌리기이 주제의 동사: 물결 모양으로 이어진 꿀 리본
예제 · 어두운 종이어두운 팬트리테두리와 반사로 그려지는 꿀
예제 · 폭 390휴대폰 폭한 단 배치, 가로 스크롤 없음

빗속의 시 카드 templates/index.html

스타일의 기본 예시: 비 맞은 읽기 카드 위의 물. 굴절률 · 분산 · 비를 페이지 위 조작판으로 바꿉니다.

템플릿 · 처음 화면비 맞은 페이지무리 지은 방울과 제목 위의 큰 방울
템플릿 · 큰 방울시 위의 물 돋보기가장자리에서 페이지로 이어지는 렌즈
템플릿 · 어두운 종이Splash버튼에서 터져 나간 방울과 물결
템플릿 · #liquid=mercury수은으로 바꾸면빛을 거의 다 반사하는 구르는 방울
