app-cube

주제를 주면 면마다 실제로 작동하는 앱이 붙은 3×3 큐브 웹페이지를 만듭니다. 타일을 끌면 층이 돌아 앱이 큐브 곳곳에 타일로 흩어지지만, 각 타일은 여전히 자기 앱의 그 부분으로 클릭되고 입력됩니다. 원본: Felix Rieseberg의 「Six Apps, One Cube」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보이며, 다른 브라우저에서는 같은 앱 여섯 개가 평범한 페이지로 나옵니다.

  • HTML-in-Canvas
  • 실시간 웹페이지
  • 3D 큐브
  • WebGL
  • 코드 전용

작업 흐름

입력
주제 한 줄 (예: 리스본 주말 여행, 밴드 투어, 빵 굽는 하루)
브리프
할 일이 서로 다른 앱 여섯 개, 240 px 타일 격자 배치, 조작 면의 문구, 재질 · 스튜디오 조명 · 소리
페이지
평범한 HTML 면 여섯 개 + AppCube.create 설정, 타일 대응 · 격자 · 돌리기 · 돌린 뒤 입력 검사
출력
index.html + lib/ 한 폴더 (file:// · Claude 아티팩트에서 동작), 검토용 스틸
node scripts/check.mjs examples/lisbon-weekend/index.html
node scripts/still.mjs examples/lisbon-weekend/index.html --out out --act idle,twist,typed,back,under
node scripts/new-page.mjs ../my-cube
node scripts/check.mjs ../my-cube/index.html

요구 사항: Node, Playwright Chromium (검사 스크립트가 HTML-in-Canvas 플래그를 켭니다). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/lisbon-weekend · 여행 플래너 큐브

샘플

예제와 템플릿을 HTML-in-Canvas를 켠 Chromium에서 찍은 스틸입니다. 카드를 누르면 그 페이지의 라이브 데모가 열립니다.

리스본 주말 examples/lisbon-weekend

계획 · 지도 · 트램 승차권 조작 면 · 짐 싸기 · 환전 · 회화, 상아색 법랑 큐브와 해 질 녘 스튜디오.

처음 화면맞춰진 큐브계획 · 지도 · 승차권 세 면이 보이는 첫 모습
섞인 뒤 입력커서를 따라 도는 큐브섞인 큐브에서 입력하자 커서 타일이 앞으로 와서 바로 섬
층 돌리기돌아가는 윗층흩어진 앱 타일 위로 한 층이 도는 순간
뒤쪽짐 싸기와 환전배경을 끌어 돌려 본 뒷면과 왼쪽 면

Desk Cube templates/index.html

스타일의 기본 예시: 메모 · 집중 타이머 · 조작 면 · 할 일 · 색 섞기 · 물 마시기, 검은 유광 큐브와 남색 스튜디오.

처음 화면책상 위 하루메모 · 타이머 · 조작 면
층 돌리기반쯤 돈 윗층타일을 끌면 그 층이 손가락을 따라 돎
섞인 뒤 입력흩어진 메모여섯 앱이 타일로 섞인 뒤에도 메모에 입력
