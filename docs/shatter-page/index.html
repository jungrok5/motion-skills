shatter-page

깨지는 판(유리 · 얼음 · 도자기 · 설탕 유리) 위에 인쇄된 실제 웹페이지를 만듭니다. 클릭하면 맞은 자리에서 금이 가고 조각이 무게를 갖고 떨어지며, 날아가는 조각 위에서도 페이지가 그대로 동작하고, 시간 슬라이더로 되감아 붙일 수 있습니다. 주제를 주면 페이지 · 재질 · 방 · 충격 방식을 새로 설계합니다. 원본: Felix Rieseberg의 「Shatter」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상 또는 Claude 데스크톱 앱에서 동작하고, 다른 브라우저에서는 같은 HTML이 일반 페이지로 보입니다.

  • HTML-in-Canvas
  • 깨지는 유리
  • 강체 물리
  • 되감기

작업 흐름

입력
주제 한 줄 (예: 박물관 "만지지 마세요" 안내판, 접시에 인쇄한 청첩장)
브리프
인쇄할 페이지와 동작할 컨트롤, 재질(균열 · 무게 · 소리), 충격 방식, 방과 빛, 이음선
검사
깨짐 · 조각 볼록성과 면적 · 낙하 · 떨어지는 조각 위 실제 클릭과 입력 · 정지 · 되감기 · 결정성 · 소리
출력
index.html + BRIEF.md + lib/ 한 폴더 (file:// · Claude 아티팩트), 스틸
node scripts/new-page.mjs ../my-pane            # 또는 --from plate-for-luck
node scripts/check.mjs ../my-pane/index.html
node scripts/still.mjs ../my-pane/index.html --out ../my-pane/out --act idle,fall,rest,mended

요구 사항: Node 18 이상, Playwright Chromium(검사와 스틸). 보는 사람은 Chrome · Edge 157 이상 또는 Claude 데스크톱 앱 단계별 순서는 SKILL.md에 있습니다.

예제 examples/plate-for-luck · 접시를 클릭하면 떨어져 깨짐

샘플

예제와 템플릿을 HTML-in-Canvas를 켠 Chromium에서 렌더한 스틸입니다. 카드를 누르면 그 장면의 라이브 데모가 열립니다.

도자기 접시 청첩장 examples/plate-for-luck

원본에 없는 주제로 브리프부터 만든 예제. 클릭하면 접시가 떨어져 타일에서 깨지고, 금으로 이어 붙입니다.

예제 · 도자기접시에 인쇄된 청첩장Save the date 이름 편집 · RSVP 체크 · 이름 입력이 되는 원형 페이지
예제 · 도자기타일에 떨어진 순간drop 클릭하면 미끄러져 떨어지고 바닥에 닿은 곳에서 깨짐
예제 · 도자기흩어진 행운의 조각pieces of luck 큰 조각 몇 개와 부스러기, 조각마다 인쇄가 보임
예제 · 도자기금으로 붙인 접시kintsugi 되감아 붙이면 깨진 자리에 금 이음선이 남음

유리판 템플릿 templates/index.html

스타일의 기본 예시. 쇠공이 날아와 유리를 깨고, 조각은 바닥에 쌓입니다.

템플릿 · 유리스튜디오 문 유리Knock softly. 창빛과 인쇄 그림자가 벽에 비치는 유리판
템플릿 · 유리쇠공이 맞은 직후throw 방사형 균열과 끊긴 고리 균열, 슬로 모션
템플릿 · 유리떨어지는 조각live on every piece 날아가는 조각 위에서도 체크와 입력이 동작
템플릿 · 유리다시 붙인 유리Mend 시간 테이프를 끝까지 되감은 뒤 남은 옅은 이음선
