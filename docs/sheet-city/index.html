sheet-city

주제를 받아, 수식과 편집과 실행 취소가 되는 진짜 스프레드시트를 책상 위 모형 도시로 그리는 라이브 웹페이지를 만듭니다. 셀마다 값만큼 높은 건물이 서고 지붕에 그 숫자가 찍히며, 지붕을 눌러 숫자를 고치면 그 셀을 읽는 셀까지 빛이 거리를 따라 달려가 건물이 함께 움직입니다. 원본: Felix Rieseberg의 「Sheet City」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보이고, 다른 브라우저에서는 같은 표가 평범한 스프레드시트 페이지로 보입니다.

  • 라이브 웹페이지
  • HTML-in-Canvas
  • 스프레드시트 도시
  • WebGL 조명
  • 코드 전용

작업 흐름

입력
주제 하나(가계부, 카페의 주간 매출, 학교 도서관 대출, 마라톤 훈련 계획 …)
브리프
시트가 답할 질문 · 열과 행(합계는 뒤, 항목은 앞) · 수식과 누적 합 · 음수가 되는 행 · 슬라이더 하나 · 한 층의 값 · 색 · 외벽 · 책상 · 빛 · 소품 · 첫 편집 · 소리를 적은 BRIEF.md
페이지
DOM 표와 편집 줄(수식 칸 · 슬라이더 · 실행 취소 · 소리)을 담은 캔버스, 그것을 모형 도시로 그리는 WebGL2(창 빛과 부드러운 그림자 · 높이 격자로 만든 차폐 · 하늘을 비추는 유리 · 소품)
확인
그림 너머 실제 클릭 · 입력 · 업로드 · 폰 폭 · 대체 페이지, 지붕 클릭 = 그 셀 선택, 편집 후 건물 이동 · 오버슈트 · 3초 안 정지 · 의존 셀로 가는 빛 · 고리, 실행 취소, 슬라이더 실제 드래그, 궤도 회전 뒤 클릭, 스틸 결정성, 오프닝, calm
출력
네트워크 없이 file:// 과 Claude 아티팩트에서 도는 폴더 하나(index.html + lib/), 스틸 PNG
node scripts/check.mjs examples/marathon-block/index.html
node scripts/still.mjs examples/marathon-block/index.html --out out --act idle,edit,close --at 0.35
node scripts/new-page.mjs ../my-sheet
node scripts/check.mjs ../my-sheet/index.html

요구 사항: 확인과 스틸에 Node + Playwright Chromium. 페이지 자체는 아무것도 필요 없습니다(시스템 글꼴, 합성 소리). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/marathon-block · 12주 마라톤 훈련 계획 · 지붕을 눌러 숫자 입력

샘플

예제(마라톤 훈련 계획, 저녁 빛의 나무 탁자)와 템플릿(가계부, 오후 빛의 커팅 매트)을 HTML-in-Canvas를 켠 Chromium에서 찍은 스틸입니다. 카드를 누르면 그 페이지의 라이브 데모가 열립니다.

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 Felix Rieseberg가 Claude 데스크톱 앱의 HTML-in-Canvas를 소개하며 공개한 열다섯 데모 가운데 「Sheet City」입니다. 이 스킬은 그 형식(진짜 표가 책상 위 모형 도시가 되고, 지붕이 셀이며, 고친 값이 거리를 따라 퍼지는 문법)과 기법만 가져오고, 코드 · 셰이더 · 데이터 · 소리와 예제는 모두 이 레포의 것입니다.
