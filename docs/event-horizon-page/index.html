event-horizon-page

주제를 주면 그 주제의 실제 웹페이지(물리 강의 노트, 밴드의 투어 페이지, 뉴스레터, 이력서, 제품 출시 페이지 …)를 만들고, 그 위에 주제에 맞게 설계한 천체 하나(강착 원반이 빛나는 블랙홀, 빔이 도는 펄서, 페이지의 반대편이 보이는 웜홀)를 띄워 중력 렌즈로 페이지를 휘게 합니다. 빛의 경로는 슈바르츠실트 궤도 방정식 u″ = 3u² − u로 적분한 표에서 나오고, 원반은 빛이 원반면을 지나는 자리에서 그려져 뒤쪽이 그림자 위로 휘어 보입니다. 천체는 끌어서 던질 수 있고, 단어를 먹이면 그 단어가 페이지에서 찢겨 나선을 그리며 빨려 들어가고, Hungry를 켜면 닿는 글자를 먹고 Restore로 모두 돌려줍니다. 휘어진 글자도 선택되고 제목은 다시 쓸 수 있으며 버튼은 보이는 자리에서 눌립니다. 원본: Felix Rieseberg의 "Event Horizon" 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 코드는 모두 새로 썼습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보입니다. 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas · WebGL2
  • 중력 렌즈 · 측지선 표
  • 블랙홀 · 펄서 · 웜홀
  • 살아 있는 페이지
  • 코드 전용

작업 흐름

입력
주제 하나(밴드의 투어 페이지, 물리 강의 노트, 뉴스레터, 이력서, 브랜드 출시 페이지 …)
브리프
어떤 페이지인지 · 실제 문장의 제목과 본문 · 먹이는 입력칸의 이름 · 팔레트 · 천체의 종류와 크기 · 다섯 빛깔 램프 · 원반 · 빔 · 목구멍 · 쉬는 자리와 첫 장면의 단어 · 먹였을 때 일어나는 일 · 소리를 적은 BRIEF.md
페이지
주제의 실제 HTML과 CSS, 캔버스 밖의 조작판(Gravity · Mass · Hungry · Restore · Sound), EventHorizon.create({...})와 주제마다의 동작(onFeed, 체크리스트)
확인
스틸 채점(쉬는 모습의 읽힘 · 렌즈 · 천체의 빛 · 실처럼 늘어나는 조각 · 휴대폰) · 약한 장 극한과 광자구 · 먼 곳은 그대로 · 끌기 오차와 던진 뒤 멈춤 · 휜 버튼 클릭 · 휜 글자 선택 · 먹이기 · Hungry와 Restore · 질량 · 결정적 스틸 · 소리
출력
index.html + lib/ 한 폴더(file:// · Claude 아티팩트에서 동작, 네트워크 없음), 스틸 PNG
cd event-horizon-page
node scripts/check.mjs examples/pulsar-tour/index.html
node scripts/still.mjs examples/pulsar-tour/index.html --out out --at 1.3 --act "move:.6,.55"
node scripts/new-page.mjs ../my-event-horizon
node scripts/check.mjs ../my-event-horizon/index.html

요구 사항: Node + Playwright Chromium(스크립트가 --enable-blink-features=CanvasDrawElement로 기능을 켭니다). 네트워크와 npm install이 필요 없습니다. 단계별 순서는 SKILL.md에 있습니다.

예제 examples/pulsar-tour · 펄서 · 신청곡마다 빨라지는 회전

샘플

예제(밴드의 투어 페이지와 펄서)와 템플릿(물리 강의 노트와 블랙홀, 다른 천체로 바꾼 미리보기)의 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

Halcyon Static 「Pulsar Season」 예제 · 펄서

가상의 밴드가 여는 여섯 밤의 투어 페이지입니다. 원본에 없는 주제로 브리프부터 검사와 스틸 채점까지 끝낸 예제입니다.

쉬는 모습제목 옆의 펄서보라 강착 고리, 청록 빔, 휘어 들어가는 날짜 목록
렌즈날짜 위로 끌어 온 별아인슈타인 고리, 안쪽의 뒤집힌 상, 그래도 눌리는 Tickets 버튼
먹이기신청곡 한 곡곡명은 목록에 남고 복사본이 빨려 들며 별이 빨라짐
Hungry투어를 먹는 별닿는 날짜와 버튼이 찢겨 들어가고 Restore로 되돌림

「Light takes the long way.」 템플릿 · 블랙홀

물리 강의 노트 한 장과 블랙홀입니다. 새 페이지의 출발점이며, 주소에 #kind=wormhole이나 #kind=neutron을 붙이면 다른 천체로 바꿔 봅니다.

쉬는 모습제목 끝의 블랙홀기울어진 원반, 그림자 위로 휜 원반 뒷면, 따뜻한 번짐
렌즈문단 위의 블랙홀휜 문장도 선택되고, 휜 버튼도 눌림
Hungry문단을 먹는 블랙홀가까운 쪽부터 늘어나며 달아오르는 글자의 실
다른 천체웜홀목구멍 안에 반전된 색의 페이지 반대편
