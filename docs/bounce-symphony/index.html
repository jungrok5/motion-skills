bounce-symphony

주제나 곡을 주면 어두운 스튜디오 바닥에 선 루브 골드버그 음악 기계를 만듭니다. 가는 기둥마다 마림바 막대 · 글로켄슈필 건반 · 볼 · 공(gong) 같은 패드가 하나씩 달려 있고, 공이 패드에서 패드로 튕기며 음 하나하나를 정확히 박자에 맞춰 칩니다. 맞은 패드는 음높이의 색으로 빛나며 흔들리고, 긴 음 앞에서는 공이 깔때기로 들어가 레일을 굴러 내려와 제때 다음 패드로 날아갑니다. 그리고 무엇도 저절로 시작하지 않습니다: 작은 진자 망치가 시작판을 쳐 도미노 줄들이 바닥으로 달려 나가고, 도미노 줄 끝의 레버가 줄을 당겨 드로퍼 뚜껑을 열거나 쥐덫 투석기를 튕겨 다음 공을 첫 패드로 날립니다. 맞은 패드는 밀대를 흔들어 다른 줄을 깨우고, 컵에 들어간 공은 컵을 기울여 나선 탑을 돌아 내려와 또 다른 줄을 넘어뜨립니다. 줄은 갈라지고, 레인들이 서로를 깨웁니다. 패드의 위치와 기울기, 도미노의 개수 · 높이 · 간격, 나선의 바퀴 수, 레일의 길이는 모두 그 순간에 정확히 끝나도록 계산하고, 독립된 순방향 물리 시뮬레이션으로 증명하며, 소리도 같은 타격과 딸깍 소리에서 합성합니다. 보고 만든 원본: Seung Joon Choi의 Facebook 영상 「튕기는 공의 교향곡 (루브골드버그 머신 + 음악)」.

작업 흐름

입력
주제 하나(“등대지기를 위한 자장가”, “로봇 공장 행진곡”), 또는 영상용으로 새로 쓸 곡 · 사용자의 곡 · 퍼블릭 도메인 곡
브리프
한 줄 느낌, 곡의 출처와 권리, 조 · 박자 · 템포와 음악 사건, 레인(한 줄 선율)마다의 악기와 움직임과 공의 색, 위에서 본 기계의 평면도, 악기 몸체와 방, 음악 사건마다의 샷, 믹스를 적은 BRIEF.md
기계
레인의 음표를 레이아웃(나선 · 호 · 지그재그 · 그린 경로) 위에 놓고, 음마다 다음 패드의 높이와 기울기를 역탄도 계산으로 찾음. 긴 음은 깔때기와 레일(구르는 공, a = 5/7·g·sin α), 이어 칠 수 없으면 새 공(드로퍼 또는 쥐덫 투석기 → 패드 → 컵)
원인 사슬
출발마다 원인을 찾음: 같은 레인의 앞 컵 → 나선 탑, 다른 레인의 타격 → 밀대, 이미 깔린 줄의 가지, 맨 처음은 시작 망치. 바닥의 모든 발 · 탑 · 줄을 피해 길을 찾아(A*) 도미노 줄을 깔고, 개수 · 높이 · 간격을 그 순간에 끝나도록 풀이
확인
마디 검사, 모든 음에 패드가 있는지, 모든 출발에 2 ms 안에 도착하는 원인이 있는지, 공마다 드로퍼에서 놓아 실제로 날려 보는 순방향 시뮬레이션(타격 2 ms 이내, 다른 패드 · 기둥 · 바닥에 안 닿음), 무엇도 무엇을 관통하지 않는지, 카메라가 치는 공을 담는지 · 패드를 뚫지 않는지, 결정성, 소리
출력
30fps 1920×1080 MP4와 WAV, ▶ 버튼으로 소리를 합성해 화면과 함께 재생하는 라이브 페이지
cd bounce-symphony/examples/lighthouse-lullaby
node ../../scripts/check.mjs index.html
node ../../scripts/render.mjs index.html --sheet --scale .5
node ../../scripts/render.mjs index.html --preview
node ../../scripts/render.mjs index.html
node ../../scripts/new-piece.mjs ~/my-piece

요구 사항: Node + Playwright Chromium, ffmpeg. GPU · npm 설치 · API 키가 필요 없습니다(기계와 원인 사슬 계산은 페이지를 열 때 2–5초, CPU WebGL에서 1920×1080 한 프레임 약 1.3초, 35.7초 템플릿 미리보기를 워커 4개로 약 2분). 생성 모델을 쓰지 않는 코드 전용 스킬입니다. 단계별 순서는 SKILL.md에 있습니다.

샘플

원본 영상에 없는 주제로 브리프부터 새로 설계한 예제, 시작 템플릿, 검토용 이미지입니다. 카드를 누르면 그 순간이 라이브 페이지에서 멈춘 채 열립니다.

「Lighthouse Lullaby」 등대지기를 위한 자장가 3/4 · ♩=84 · F장조 · 31.7초 · 도미노 약 1,000개

비브라폰 막대로 쌓은 원뿔 등대를 파도(하늘색 공)가 돌며 내려오고, 바깥 고리의 칼림바가 노래하고, 투석기가 볼을 위한 공을 날리고, 공(gong)이 악구 끝을 알립니다. 시작 망치는 등대 안에 서 있고, 볼의 공은 컵에서 나선 탑을 돌아 내려와 다음 볼의 투석기를 깨웁니다. 밤의 푸른 방, 따뜻한 등 하나

시작 · 1.4초등대에서 달려 나가는 줄시작 망치가 친 판에서 첫 두 줄이 출발
3.6초기계 전체나선 탑 12개, 도미노 줄 25개, 투석기 13개
3마디등대 안쪽파도 레인을 따라가는 샷
6마디볼의 릴레이컵이 기울고 공이 나선을 돌아 다음 투석기의 도미노로
12마디마지막 하강높은 A로 끝나는 파도
끝 · 31.2초모두 쓰러지고 멈춤마지막 공(gong)의 여음 속에 멀어지는 샷

「Marble Canon」 시작 템플릿 4/4 · ♩=96 · D장조 · 12마디 · 35.7초 · 도미노 약 1,100개

가운데 마림바 나선이 화음을 8분음표 아르페지오로 굴리고, 둘레 고리에서 글로켄슈필 선율 · 투석기로 날리는 베이스 마림바 · 싱잉볼이 연주합니다. 볼의 컵이 아르페지오의 두 번째 공을, 아르페지오의 컵이 선율의 첫 공을, 베이스 타격이 볼을 깨웁니다. 새 작품은 여기서 시작해 주제에 맞게 바꿉니다

2마디음높이의 빛맞은 막대가 그 음의 색으로 빛났다가 식음
4마디선율을 깨우는 릴레이아르페지오의 컵이 기울어 나선 → 도미노 → 드로퍼
6마디깔때기와 레일2분음표를 한 공이 굴러서 버팀
