bounce-symphony

주제나 곡을 주면 어두운 스튜디오 바닥에 선 루브 골드버그 음악 기계를 만듭니다. 가는 기둥마다 마림바 막대 · 글로켄슈필 건반 · 볼 · 공(gong) 같은 패드가 하나씩 달려 있고, 작은 뚜껑이 열리면 공이 떨어져 패드에서 패드로 튕기며 음 하나하나를 정확히 박자에 맞춰 칩니다. 맞은 패드는 음높이의 색으로 빛나며 흔들리고, 악구가 끝난 공은 컵에 떨어져 멈춥니다. 기계는 악보에서 거꾸로 설계하고(실제 포물선과 반발 계수로 다음 음 시각에 다음 패드에 닿도록 패드마다 위치와 기울기를 계산) 독립된 순방향 물리 시뮬레이션으로 증명하며, 소리도 같은 타격에서 합성합니다. 보고 만든 원본: Seung Joon Choi의 Facebook 영상 「튕기는 공의 교향곡 (루브골드버그 머신 + 음악)」.

  • 역설계 물리
  • 순방향 시뮬레이션 검증
  • three.js 스튜디오
  • 모달 타악기 합성
  • MP4 · 라이브 페이지

작업 흐름

입력
주제 하나(“등대지기를 위한 자장가”, “로봇 공장 행진곡”), 또는 영상용으로 새로 쓸 곡 · 사용자의 곡 · 퍼블릭 도메인 곡
브리프
한 줄 느낌, 곡의 출처와 권리, 조 · 박자 · 템포와 음악 사건, 레인(한 줄 선율)마다의 악기와 움직임과 공의 색, 위에서 본 기계의 평면도, 악기 몸체와 방, 음악 사건마다의 샷, 믹스를 적은 BRIEF.md
기계
레인의 음표를 레이아웃(나선 · 호 · 지그재그 · 그린 경로) 위에 놓고, 음마다 다음 패드의 높이와 기울기를 역탄도 계산으로 찾음. 이어 칠 수 없는 긴 음은 새 공(드로퍼 → 패드 → 컵)
확인
마디 검사, 모든 음에 패드가 있는지, 공마다 드로퍼에서 놓아 실제로 날려 보는 순방향 시뮬레이션(타격 2 ms 이내, 다른 패드 · 기둥 · 바닥에 안 닿음), 무엇도 무엇을 관통하지 않는지, 카메라가 치는 공을 담는지 · 패드를 뚫지 않는지, 결정성, 소리
출력
30fps 1920×1080 MP4와 WAV, ▶ 버튼으로 소리를 합성해 화면과 함께 재생하는 라이브 페이지
cd bounce-symphony/examples/lighthouse-lullaby
node ../../scripts/check.mjs index.html
node ../../scripts/render.mjs index.html --sheet --scale .5
node ../../scripts/render.mjs index.html --preview
node ../../scripts/render.mjs index.html
node ../../scripts/new-piece.mjs ~/my-piece

요구 사항: Node + Playwright Chromium, ffmpeg. GPU · npm 설치 · API 키가 필요 없습니다(CPU WebGL에서 1920×1080 한 프레임 약 1초, 31.7초 예제 미리보기를 워커 4개로 약 1분 반). 생성 모델을 쓰지 않는 코드 전용 스킬입니다. 단계별 순서는 SKILL.md에 있습니다.

예제 examples/lighthouse-lullaby · 3/4 자장가 · 공 28개 · 패드 100개 · 31.7초 · ▶ 버튼으로 소리

샘플

원본 영상에 없는 주제로 브리프부터 새로 설계한 예제, 시작 템플릿, 검토용 이미지입니다. 카드를 누르면 그 순간이 라이브 페이지에서 멈춘 채 열립니다.

「Lighthouse Lullaby」 등대지기를 위한 자장가 3/4 · ♩=84 · F장조 · 31.7초

비브라폰 막대로 쌓은 원뿔 등대를 파도(하늘색 공)가 돌며 내려오고, 바깥 고리의 칼림바가 노래하고, 볼이 화음을, 공(gong)이 악구 끝을 알립니다. 밤의 푸른 방, 머리 위 따뜻한 등 하나, 호박색과 바다 청록으로 빛나는 막대

시작 · 1.5초고리 안의 등대첫 공이 떨어지기 전, 기계 전체를 도는 샷
3마디등대 안쪽파도 레인을 따라가는 샷, 공 위로 막대가 빛남
5마디바닷가의 노래칼림바 선율, 짧은 사슬마다 새 공
9마디빛의 띠지나간 타격이 천천히 식으며 나선을 그림
12마디마지막 하강높은 A로 끝나는 파도, 막대마다 남은 빛
끝 · 31.2초모두 컵 안에마지막 공(gong)의 여음 속에 멀어지는 샷

「Marble Canon」 시작 템플릿 4/4 · ♩=96 · D장조 · 12마디 · 35.7초

가운데 마림바 나선이 화음을 8분음표 아르페지오로 굴리고, 둘레의 고리에서 글로켄슈필 선율 · 베이스 마림바 · 싱잉볼이 연주합니다. 회색 스튜디오와 무지개 음높이 색. 새 작품은 여기서 시작해 주제에 맞게 바꿉니다

시작 · 1.5초소용돌이와 고리드로퍼마다 공이 대기 중인 첫 장면
2마디음높이의 빛맞은 막대가 그 음의 색으로 빛났다가 식음
4마디첫 악구의 끝기계 둘레를 도는 샷
8마디막대 사이로 낮게아르페지오를 바닥 높이에서 따라감
9마디모두 연주선율이 올라가는 마디, 넓은 샷
11마디베이스 걸음단단한 막대(e 0.92)에서 공 하나가 열 음쯤

검토 평면도 · 시트

브리프의 평면도가 화면에 그대로 나왔는지 위에서 확인하고, 샷마다 시작 · 정착 순간을 한 장에 모아 검토 기준으로 채점합니다
