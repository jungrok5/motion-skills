# Fonts

Captions and labels use `ALFSans-ksx1001.woff2`, loaded by each page with `@font-face` (`font-family: "ALF Sans"`), so pages
and renders work offline. It is a subset of Pretendard 1.3.9 Variable (weights 100–900; Latin Inter-derived, the 2,350 KS X
1001 Hangul syllables, ASCII, Latin-1, common punctuation and arrows), the same file `agent-launch-film/lib/fonts/` ships.
License: SIL OFL 1.1 — `Pretendard-LICENSE.txt`. Pretendard reserves its name under the OFL, so the subset is named
**ALF Sans**; the design and copyright are Pretendard's (Kil Hyung-jin). Another script: add a face in the page's `<style>`
and put it after `"ALF Sans"` in the film's `font` option.
