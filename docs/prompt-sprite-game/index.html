prompt-sprite-game

주제를 주면 동사 하나짜리 작은 픽셀 게임(옆에서 보는 플랫폼 오르기, 위에서 보는 아레나 모으기)을 설계하고, 주인공 · 모을 것 · 적 · 목표를 영어 몇 단어로 적어 Tessera-small이 플레이어의 브라우저 안에서 16×16 스프라이트로 그리게 합니다. 같은 캐릭터를 손그림 픽셀로도 그려 두어 오프라인에서도, 상업적 용도로도 돌아갑니다. 원본: Caleb의 X 게시물(Slack Moji, 모델 Tessera-small)을 보고 만들었습니다.

  • Tessera-small · 브라우저 안에서 16×16
  • 플랫폼 · 아레나
  • 손그림 스프라이트 함께
  • 깡충 걸음 · 예비 동작 · 숨 쉬는 대기
  • game.json 하나

작업 흐름

입력
주제 하나 (예: 등대 고양이, 버섯 숲 바구니)
브리프
동사 · 종류 · 캐스트(프롬프트 · 바라보는 쪽 · 질량 · 걸음) · 장소 · 레벨 순서 · 곡 · 문구
스프라이트
Tessera 미리보기(시드마다 네 장)에서 고르기, 같은 모습의 손그림 16×16 격자
검사
도달 가능성 · 결정성 · 디딘 몸 미끄러짐 · 숨 쉬는 대기 · 예비 동작 · 착지 · 멈춤 관성, 좌우 양쪽 캐스트 시트
꾸미기
같은 주인공에 모자 · 왕관 · 선글라스 · 목도리만 다시 그리기(나머지 픽셀은 그대로)
테마 모델
(선택) 같은 데이터(CC0)의 한 테마로 직접 학습한 작은 모델, 예: 고양이 전용 3.6 MB · CPU로 네 장에 4~5초
출력
index.html + game.json + lib/, 정적 서버 어디서나
node prompt-sprite-game/scripts/new-game.mjs my-game --kind=platform --title="My Game"
node prompt-sprite-game/scripts/paint.mjs my-game    # Tessera 미리보기 → ref/
node prompt-sprite-game/scripts/check.mjs my-game
node prompt-sprite-game/scripts/sheet.mjs my-game    # 캐스트 시트 + 스틸
cd my-game && python3 -m http.server 8000

요구 사항: Node 18+, Playwright Chromium(스크립트). 게임은 정적 서버와 브라우저만, Tessera는 huggingface.co · cdn.jsdelivr.net 접속과 (빠르게 그리려면) WebGPU가 필요합니다. Tessera-small은 CC BY-NC 4.0이라 모델이 그린 스프라이트로 하는 게임은 비상업용입니다. 단계별 순서는 SKILL.md에 있습니다.

「등대 고양이」 · 플랫폼 · 「고양이 모델로 그리기」 · ← → 이동, Space 점프

샘플

이 스킬로 만든 두 게임과 검사 결과입니다. 사진은 모두 손그림 스프라이트로 찍었습니다. 모델이 그리는 스프라이트는 데모에서 직접 보실 수 있습니다. 「등대 고양이」의 「고양이 모델로 그리기」는 이 레포에서 학습한 고양이 전용 모델(3.6 MB)이 몇 초 만에 주인공을 그리고, 「Tessera로 스프라이트 그리기」는 Tessera-small이 캐스트 전체를 그립니다(처음 한 번 115 MB). 「내 주인공 그리기」의 「꾸미기」 버튼은 지금 주인공의 그 부분만 Tessera로 다시 그립니다. 카드를 누르면 그 게임이 열립니다.

「등대 고양이」 플랫폼 · 72×12 타일 · 생선 5 · 목숨 3

폭풍에 꺼진 등대를 다시 켜려고 고양이가 밤바다 절벽을 오릅니다. 게는 밟고, 성게와 바다는 피하고, 틈 위를 오가는 갈매기는 때를 맞춰 넘습니다.

플랫폼 · 첫 적판자 밑의 게밟거나 넘고, 판자 위의 생선까지
플랫폼 · 겹친 위험틈 위의 갈매기미끄러지듯 나는 몸은 위아래로 떠 있습니다
플랫폼 · 목표꼭대기의 등불생선 다섯 마리를 모아야 불이 켜집니다
시작 화면Tessera로 그릴지, 손그림으로 할지모델은 누른 사람의 브라우저에서만 그리고, 「내 주인공 그리기」로 직접 적은 말로 네 장을 받아 고릅니다

「버섯 숲 바구니」 아레나 · 30×20 타일 · 버섯 10 · 75초

해 지기 전에 고슴도치가 숲속 빈터의 빨간 버섯을 바구니에 담습니다. 딱정벌레는 덮쳐서 잠깐 납작하게 만들 수 있지만, 쫓아오는 말벌은 피할 수밖에 없습니다.

아레나 · 시작빈터의 첫 버섯생울타리가 방을 나누고 연못은 돌아가야 합니다
아레나 · 쫓는 적연못가의 말벌말벌은 시야 안에 들면 따라옵니다

캐스트 시트 좌우 양쪽 · 손그림 스프라이트

움직이는 캐릭터마다 오른쪽 · 왼쪽으로 대기 · 깡충 걸음 · 멈춤 · 제자리 돌기 · 점프(웅크림 → 도약 → 꼭대기 → 착지 → 회복)를 그립니다. 회색 선은 디딘 몸의 땅입니다.

캐스트 시트 · 질량 1고양이돌 때는 제자리에서 좁아지며 뒤집히고, 멈추면 윗부분이 앞으로 넘어갔다 돌아옵니다
캐스트 시트 · 질량 1.8 · 0.5딱정벌레와 말벌무거울수록 오래 웅크리고 깊게 내려앉습니다
