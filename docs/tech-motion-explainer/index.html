tech-motion-explainer

파이프라인, 프로토콜, 서버 루프 같은 기술 과정을 60–110초 설명 영상으로 그립니다. 주제마다 영상, 설명, 용어집 페이지를 한 세트로 만들고, 영상 페이지를 MP4로도 녹화합니다.

  • 2D · 3D
  • 16:9 · 9:16
  • MP4
  • 라이브 플레이어
  • 임베드

작업 흐름

입력
기술 내용(구조, 흐름, 실제 파일 · 메시지 · 지표 이름)을 4–8개 장으로 나눈 스토리보드
영상
모든 프레임을 renderAt(t)로 그림. 장 이동, 0.75× · 0.5× 재생을 지원하는 플레이어
설명 · 용어집
영상 페이지 안의 노트로 두 페이지 생성
검증
스틸 렌더, 플레이어 자동 점검, 별도 에이전트의 전문가 리뷰
추가 형식
9:16 세로 컷, three.js로 그리는 설명 방식 7가지, 다른 페이지 안의 스크롤 재생
S=.claude/skills/tech-motion-explainer
cp -r $S/starter/assets assets
mkdir my-topic && cp $S/template.html my-topic/index.html
node $S/scripts/render.mjs my-topic/index.html /tmp/stills --stills 3,10,20

요구 사항: Node 18+ · Playwright Chromium, ffmpeg(MP4). 단계별 순서는 SKILL.md에 있습니다.
