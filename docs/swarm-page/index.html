swarm-page

주제를 받아, 페이지의 글자 픽셀이 새 · 벌 · 반딧불이 · 물고기 · 종이비행기 떼가 되어 날아올랐다가 제자리에 내려앉아 다시 읽히는 라이브 웹페이지를 만듭니다. 떼는 일곱 이웃을 따르는 규칙으로 움직여 방향 전환이 물결처럼 번지고, 페이지가 모여 있을 때는 모든 글자를 누르고 고쳐 쓸 수 있습니다. 원본: Felix Rieseberg의 「Swarm」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 코드는 모두 새로 썼습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보입니다. 다른 브라우저에서는 같은 HTML이 평범한 페이지로 나옵니다.

  • HTML-in-Canvas
  • 픽셀이 떼로 나는 페이지
  • 일곱 이웃 군집 비행
  • 라이브 웹페이지
  • 코드 전용

작업 흐름

입력
주제 하나 (양봉 장부, 공연 라인업, 졸업 공지, 관찰 일지 …)
브리프
페이지 내용과 조작, 생물(모양 · 무게 · 날갯짓), 떼의 형태, 하늘과 앞 풍경, 날리는 방법
페이지
진짜 HTML 한 장 + Swarm.start({...}) 설정, SVG 앞 풍경
검사
예비 동작 · 이륙 물결 · 관성 · 회전 제한 · 물결 전파 · 날갯짓과 활공 · 착지 흔들림 · 입력 수치
출력
네트워크 없이 도는 폴더 하나 (index.html + lib/), 스틸 PNG
node scripts/check.mjs examples/bee-ledger/index.html
node scripts/still.mjs examples/bee-ledger/index.html --out out --act fly --at 0.5,3
node scripts/new-page.mjs ../my-swarm-page
node scripts/check.mjs ../my-swarm-page/index.html

요구 사항: Node, Playwright Chromium (검사와 스틸은 HTML-in-Canvas 플래그를 켜서 실행). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/bee-ledger · 「Open the hives」를 누르고, 표를 정렬하고, 글을 고쳐 쓰기

샘플

예제와 템플릿을 HTML-in-Canvas 플래그를 켠 Chromium에서 시뮬레이션 시간으로 찍은 스틸입니다. 카드를 누르면 해당 라이브 데모가 열립니다.

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 Felix Rieseberg의 「Swarm」 데모로, 저녁 들새 조사 기록 페이지가 찌르레기 떼가 되어 호수 위를 날다 돌아옵니다. 이 스킬은 그 형식(페이지 픽셀이 곧 떼, 모이면 다시 살아 있는 페이지)만 가져오고, 엔진과 예제 「Linden Hill honey ledger」의 내용 · 생물 · 하늘은 모두 이 레포의 것입니다.
