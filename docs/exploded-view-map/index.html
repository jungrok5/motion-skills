exploded-view-map

주제 하나를 주면 등고선 지도 · 경로 · 수치와 고도 단면 · 태양 슬라이더와 두 갈래 토글 · 정류장 목록이 있는 실제 웹페이지를 만들고, HTML-in-Canvas로 그 페이지를 3D로 분해합니다. 등고선 층은 저마다의 높이에 쌓인 종이판이 되어 계단식 지형을 이루고, 카드는 독서대처럼 일어나 카메라를 향하며, 핀은 기둥 위에 섭니다. 끌면 돌아가고, 스크롤하면 층이 벌어지고, 층을 누르면 그 위가 통째로 들리며, Esc로 다시 평평한 페이지가 됩니다. 슬라이더가 정하는 햇빛이 위쪽 판들을 지나며 그림자를 드리우고, 해가 지면 핀마다 등불이 켜집니다. 분해된 채로도 제목을 입력하고 슬라이더를 끌고 정류장을 누를 수 있는 진짜 DOM이며, 종이와 책상 소리는 코드로 합성합니다. 원본: Felix Rieseberg의 「Exploded View」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 3D로 보이고, 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas · WebGL2
  • 종이판 계단 지형
  • 분해된 채로 동작하는 DOM
  • 햇빛 · 그림자 · 밤 등불
  • 합성 사운드 · 코드 전용

작업 흐름

입력
주제 하나(산호초 다이빙 계획, 도시 언덕을 넘는 자전거 길, 스키장, 포도밭 계단, 건물의 층 …)
브리프
쌓을 것(높이 함수와 높이 간격, 또는 층 목록) · 판에 찍을 것 · 두 가지 팔레트와 토글의 뜻 · 카드 네 장의 수치와 문구 · 슬라이더의 뜻 · 경로 · 핀 · 책상 · 물이나 안개 · 소리를 적은 BRIEF.md
페이지
EVTerrain 조각으로 짠 높이 함수, 카드 HTML과 CSS(휴대폰 배치 포함), ExplodedView.create 설정 하나
확인
공통 HTML-in-Canvas 검사 + 분해 · 정착 시간 · 모든 카드와 핀이 그려진 자리에서 눌리는지 · 돌린 채 입력 · 그려진 슬라이더 끌기 · 층 들기 · 팔레트 전환 · 밤 · 다시 합치기, 그리고 스틸 검토
출력
네트워크 없이 도는 한 폴더(index.html + lib/), file://과 Claude 아티팩트에서 동작, 스틸 PNG
cd exploded-view-map
node scripts/check.mjs examples/reef-dive/index.html
node scripts/still.mjs examples/reef-dive/index.html --out out --act flat,apart,night
node scripts/new-page.mjs ../my-exploded-map
node scripts/check.mjs ../my-exploded-map/index.html

요구 사항: Node + Playwright Chromium(스크립트가 --enable-blink-features=CanvasDrawElement를 켭니다). 네트워크와 npm 설치가 필요 없습니다. 단계별 순서는 SKILL.md에 있습니다.

예제 examples/reef-dive · 수심 4 m마다 10장 · 끌어서 돌리기 · 스크롤로 분해

샘플

예제 「Lantern Reef」와 시작 템플릿 「The Crater Loop」를 여러 상태로 찍은 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

「Lantern Reef」 산호초 다이빙 계획 · 수심 0–36 m

수심을 음의 높이로 둔 높이 함수에서 4 m마다 판을 잘랐습니다. 깊은 판일수록 물빛으로 물들고, 위쪽 판에는 물결 빛무늬가 흐르며, 토글은 산호를 하얗게 탈색시킵니다. 원본에 없는 주제로 브리프부터 끝까지 만든 예제입니다.

분해 · 살아 있는 산호층층이 떠오른 산호초물빛으로 물드는 깊은 판, 경로 리본, 기둥 위의 핀
평면 · 실제 페이지분해 전의 다이빙 계획최대 수심 · 거리 · 시간 · 공기 소모, 수심 단면
토글 · 탈색해양 열파 뒤의 같은 산호초팔레트 전환이 판을 다시 올림
슬라이더 · 밤해가 진 뒤달빛, 핀마다 등불, 빛나는 경로

「The Crater Loop」 시작 템플릿 · 화산섬 자전거 일주

해수면부터 50 m마다 판을 자른 화산섬입니다. 새 페이지는 이 템플릿이나 예제에서 시작해 주제에 맞게 다시 설계합니다.

분해 · 건기계단식 화산섬분화구 둘레까지 오르는 경로 리본
층 들기 · 우기한 층을 눌러 들어 올리기그 위의 층이 함께 들려 아래가 보임

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 Felix Rieseberg가 Claude 데스크톱 앱에 HTML-in-Canvas를 켜며 공개한 데모 열다섯 개 중 「Exploded View」입니다. 등산 계획 페이지의 지도와 카드가 3D로 분해되고, 등고선 띠가 종이판으로 쌓이며, 분해된 채로 모든 카드가 동작합니다. 이 스킬은 그 형식과 기법만 가져오고, 엔진 · 지형 · 문구 · 소리는 모두 새로 썼습니다.
