wet-ink-page

주제 하나(시 한 편, 찻집 메뉴판, 전시 개막 초대장, 선언문 …)를 주면 젖은 잉크로 인쇄된 살아 있는 웹페이지를 만듭니다. 페이지를 끌면 실제 DOM의 글자와 색 덩어리가 마블링 물판처럼 리본 · 갈고리 · 초승달로 휘저어지고, 손을 뗀 뒤에도 잉크의 점도만큼 흘러가다 멈춥니다. 누르면 안료 방울이 피어나며 둘레의 글자를 밀어내고, 그 사이에도 입력창에 글을 쓰고 흘러간 버튼을 누를 수 있습니다. Esc를 누르면 기록해 둔 흐름을 거꾸로 돌려 모든 글자가 제자리로 돌아갑니다. 내용 · 종이 · 이름 붙인 안료 · 점도 · 빗(펜 · 빗 · 차선) · 방울 · 자동 시연을 주제마다 새로 설계하고, 결과물은 네트워크 없이 도는 폴더 하나입니다. 원본: Felix Rieseberg의 「Ink」 데모(HTML-in-Canvas 데모 페이지, X 게시물)을 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 동작하고, 다른 브라우저에서는 같은 HTML이 평범한 페이지로 보입니다.

  • HTML-in-Canvas · WebGL2
  • 마블링 · 변위 맵
  • 입력 · 클릭되는 실제 페이지
  • Esc 되감기
  • 코드 전용

작업 흐름

입력
주제 하나(시, 메뉴판, 전시 초대장, 선언문, 프로그램 …)
브리프
헤드라인과 입력이 뜻하는 것 · 본문 · 단색 덩어리 2–3개 · 종이와 주제에 맞게 이름 붙인 안료 3–6개 · 점도 · 빗의 살 수 · 방울 · 자동 시연 · 스틸용 장면을 적은 BRIEF.md
페이지
창 하나 크기의 실제 HTML 페이지와 window.INK 설정(엔진 lib/wet-ink.js, 런타임 lib/hic.js)
확인
공통 검사(그리기 · 왜곡 너머 클릭과 입력 · 휴대폰 폭 · 대체 페이지)와 휘젓기 이동량(px) · 흐름 정지 시간 · 방울 색 · 흘러간 칩 클릭 · 흘러간 입력창 클릭과 입력 · 점도 비교 · 되감기 후 차이 · 스틸 결정성, 1280 · 390 스틸 검토
출력
index.html + lib/ 폴더 하나(파일로 열기 · Claude 아티팩트), 스틸 PNG
cd wet-ink-page
node scripts/check.mjs examples/tea-room/index.html
node scripts/still.mjs examples/tea-room/index.html --out out --at 1,8 --act latte,whisk
node scripts/new-page.mjs ../my-page
node scripts/check.mjs ../my-page/index.html

요구 사항: Node + Playwright Chromium(스크립트가 CanvasDrawElement 플래그를 켭니다). 네트워크와 npm 설치가 필요 없습니다. 헤드리스 검사는 소프트웨어 GL이라 페이지 하나에 몇 분 걸립니다. 단계별 순서는 SKILL.md에 있습니다.

「Low Tide Tea Room」 찻집의 오늘 메뉴

원본에 없는 주제로 브리프부터 끝까지 만든 예제입니다. 다섯 살 차선(whisk)으로 휘젓고, 누르면 우유가 과녁 모양으로 피어나며, 휘젓는 동안에도 Pour 버튼이 쟁반에 잔을 담습니다.

정지 상태인쇄된 메뉴판헤드라인, 찻사발 두 개, 메뉴 다섯 줄, 차 색 안료
방울 · 차선우유 과녁을 가르기피어나며 밀어내는 방울, 다섯 살로 끌어내린 우유
지그재그 · 말차휘저은 헤드라인글자는 리본으로, 원은 혀와 초승달로
자동 시연 · 11초움직이는 동안 입력오늘의 특선을 입력하는 사이 메뉴 위로 히비스커스
휴대폰 폭 390한 단 배치메뉴판과 템플릿, 가로 스크롤 없이 안료는 한 줄로

시작 템플릿 시 한 편의 브로드사이드

새 페이지의 출발점입니다. 쪽빛 · 주홍 · 황토 · 램프 블랙과 '물'(안료 없이 휘젓기), 펜 하나의 빗.

정지 상태브로드사이드큰 제목, 주홍 원, 시, 안료 띠
자동 시연 · 9초흐르는 제목물결 한 번, 원 위의 방울, 주홍 나선
방울 + 지그재그마블링섞이지 않는 안료, 가는 종이 이음선

실제 작품

이 레포에서 만든 스킬입니다. 출발점은 Felix Rieseberg가 Claude 데스크톱 앱에 HTML-in-Canvas를 켜며 공개한 데모 열다섯 개 중 「Ink」입니다. 젖은 잉크로 인쇄된 견본 한 장을 끌면 잉크가 손을 따라 흐르고, 누르면 안료 방울이 떨어지고, Esc를 누르면 모든 글자가 제자리로 돌아갑니다. 이 스킬은 그 재료와 상호작용의 문법, 기법의 계열만 가져오고, 엔진 코드와 예제의 내용 · 디자인은 모두 이 레포의 것입니다.
