jelly-page

주제를 받아, 손으로 당기면 출렁이는 젤리 속에 진짜 웹페이지를 굳혀 넣은 라이브 페이지를 만듭니다. 글자는 젤리 속 사탕처럼 보이지만 그대로 입력하고 누를 수 있고, 온도를 올리면 녹아서 평범한 페이지가 됩니다. 원본: Felix Rieseberg의 「Jelly」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 코드는 모두 새로 썼습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보입니다. 다른 브라우저에서는 같은 HTML이 평범한 페이지로 나옵니다.

  • HTML-in-Canvas
  • 젤리 물리
  • 굴절과 반사
  • 라이브 웹페이지
  • 코드 전용

작업 흐름

입력
주제 한 줄 (아이 생일 초대장, 빵집 오늘의 메뉴, 제품 출시 알림)
브리프
페이지의 할 일과 입력 요소, 맛과 색, 틀 모양, 식탁보 · 접시 · 방, 젤리 속 알갱이, 소리
페이지
진짜 HTML과 CONFIG, 컨트롤 연결 (새 페이지 스크립트로 시작)
검사
당기기 · 흔들림이 잦아드는 시간 · 흔들리는 중 클릭 · 떨어뜨리기 · 녹이기 · 소리 · 스틸 결정성
출력
폴더 하나 (index.html + lib/), 상태별 스틸
node jelly-page/scripts/new-page.mjs my-jelly
node jelly-page/scripts/check.mjs my-jelly/index.html
node jelly-page/scripts/still.mjs my-jelly/index.html --out my-jelly/out --act drop --at 0.3,0.85

요구 사항: Node, Playwright Chromium (스크립트가 HTML-in-Canvas 플래그를 켭니다). 네트워크 · 이미지 · 폰트 없음. 단계별 순서는 SKILL.md에 있습니다.

예제 examples/party-invite · 젤리를 끌어당기고, 이름을 쓰고 RSVP

샘플

예제와 템플릿을 HTML-in-Canvas를 켠 Chromium에서 상태별로 찍은 스틸입니다. 카드를 누르면 라이브 데모가 열립니다.

생일 초대장 examples/party-invite

아이 생일 초대장: 이름 줄, 날짜, RSVP 입력과 버튼. 2단 타원 틀, 도자기 접시, 땡땡이 종이 식탁보, 스프링클과 기포.

정지 · 라즈베리굳은 젤리창문이 비치는 윗면, 색이 물든 그림자
당기기끌어당긴 순간눌린 자리를 따라 페이지도 함께 휘어짐
떨어뜨리기 · 0.3초들어 올림아래로 늘어진 몸, 떨어져 나간 부드러운 그림자
떨어뜨리기 · 0.86초착지허리가 불룩해지는 찌그러짐과 옆으로 쏠림
맛 바꾸기블루 라즈베리젤리 색과 식탁보 무늬 색이 함께 바뀜

시작 템플릿 templates/index.html

스타일의 예시: 둥근 사각 틀, 줄무늬 식탁보, 유리 접시, 과일 알갱이.

정지 · 딸기Jiggle물결 모양 밑단, 속에 박힌 과일 알갱이
맛 바꾸기라임식탁보가 보색으로 바뀜
녹이기반쯤 녹은 젤리시점이 위에서 내려다보는 쪽으로, 끝까지 녹이면 평범한 페이지
