time-machine-page

주제를 받아, 제목을 고치고 메모를 적을 수 있는 진짜 웹페이지 하나를 다이얼로 시대를 넘기며 그 시대의 재료로 그리는 라이브 웹페이지를 만듭니다. 시대마다 같은 DOM을 CSS로 다시 짜고 셰이더 패스(활판과 망점, 필름 입자와 흔들림, 형광 주사선, 목판, 등사, 디더링, 홀로그램)로 그리며, 다이얼을 돌리면 카메라가 종이의 망점이나 필름 입자 속으로 파고들었다가 다음 시대의 재료로 바뀌어 빠져나옵니다. 원본: Felix Rieseberg의 「Time Machine」 데모(HTML-in-Canvas 데모 페이지, X 게시물)를 보고 만들었습니다. 라이브 데모는 Chrome · Edge 157 이상이나 Claude 데스크톱 앱에서 보이고, 다른 브라우저에서는 같은 HTML이 다이얼이 동작하는 평범한 페이지로 보입니다.

작업 흐름

입력
주제 하나(레시피, 마을 소식, 밴드 공연 포스터, 학교 시간표, 제품 소개 …)
브리프
문서와 슬롯 · 독자가 만질 컨트롤 · 그림 하나 · 주제의 역사에 맞는 3–5개 시대(연도 · 매체 · 그 시대의 말투와 단위 · 레이아웃 · 패스 · 둘레 · 다이브 지점 · 소리)를 적은 BRIEF.md
페이지
슬롯과 메모 기록을 담은 DOM 하나, 시대별 CSS, 시대마다 패스로 짠 셰이더(필요하면 새 패스), 무게감 있는 다이얼과 다이브 여행, 확대, X-ray, 합성 소리
확인
그림 너머 실제 클릭 · 입력 · 폰 폭 · 대체 페이지, 모든 시대에서 메모 입력과 등록, 시대끼리 다른 그림, 다이얼 실제 드래그의 다이브 깊이와 착지, 키 · 버튼 · 대기열, 확대 뒤 클릭, X-ray, 소리, calm
출력
네트워크 없이 file:// 과 Claude 아티팩트에서 도는 폴더 하나(index.html + lib/), 스틸 PNG
node scripts/check.mjs examples/daily-loaf/index.html
node scripts/still.mjs examples/daily-loaf/index.html --out out --all
node scripts/still.mjs examples/daily-loaf/index.html --out out --era ditto --travel woodcut,0.3
node scripts/new-page.mjs ../my-time-machine

요구 사항: 확인과 스틸에 Node + Playwright Chromium. 페이지 자체는 아무것도 필요 없습니다(시스템 글꼴, 인라인 SVG, 합성 소리). 단계별 순서는 SKILL.md에 있습니다.

예제 examples/daily-loaf · 빵 레시피 · 1450 목판 → 1962 등사 → 1996 웹 → 2040 홀로그램

샘플

예제와 템플릿을 시대별로, 그리고 시대 사이를 여행하는 순간과 확대한 재료를 찍은 스틸입니다. 카드를 누르면 그 페이지의 라이브 데모가 열립니다.

빵 레시피 examples/daily-loaf

같은 레시피 카드가 네 시대를 지납니다. 빵 개수를 바꾸면 재료가 그 시대의 단위로 다시 계산되고, 적은 메모는 쓴 해와 함께 따라옵니다.

1450 · 목판좋은 흰 빵 굽는 법woodcut · paper · desk 패스, 붉은 머리글자는 그대로
1962 · 등사가정 시간 유인물예제 안에서 새로 쓴 ditto 패스: 보라 잉크 · 번짐 · 흐려짐 · 겹상
1996 · 웹 페이지밥의 빵 페이지640×480 원본 픽셀 · 216색 디더링 · 주사선 · 섀도 마스크 · 볼록 유리
2040 · 홀로그램주방 비서의 사워도우holo · bloom · lab 패스, 색 번짐과 간섭 띠

도서관 템플릿 templates/index.html

스타일의 기본 예시입니다. 마을 도서관 소식이 신문, 뉴스릴, 도서 목록 단말기로 바뀝니다.

1904 · 신문무료 도서관 개관letterpress · halftone · paper(접힌 자국) · desk
1937 · 뉴스릴백만 번째 책 대출weave · mono · grain · dust · cinema · flicker
1979 · 터미널카드 목록이 컴퓨터로barrel · mono(형광) · bloom · scanlines · mask · monitor

여행과 확대 #travel · #zoom

다이얼을 돌린 순간을 멈춰 찍었습니다. 카메라가 재료 속으로 들어가 다음 시대의 재료로 바뀝니다.

여행 · 30%목판 속으로 다이브1450 → 1962, 칼선이 화면을 채우는 순간
여행 · 42%형광 줄무늬에서 빛으로1996 → 2040, 깊은 곳에서 재료가 바뀜
확대 · ×6망점과 잉크휠로 확대해도 페이지는 그대로 클릭되고 입력됨
