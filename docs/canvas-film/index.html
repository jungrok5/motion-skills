canvas-film

장면마다 다른 화풍으로, HTML Canvas만으로 그리는 시네마틱 영상. 같은 장면 파일로 MP4 녹화(가로·세로)와 웹 실시간 재생을 모두 하고, 언어 파일만 더하면 다국어가 됩니다.

  • 16:9 · 9:16
  • MP4
  • 라이브 플레이어
  • 사운드
  • 다국어

어떻게 쓰나

  • 입력 — 이야기 · 대본 · 사이트 글. 장면(20–60초)으로 나누고, 장면마다 의미에 맞는 화풍을 고릅니다.
  • 장면 — 장면 하나가 HTML 파일 하나. seek(t)로 어느 프레임이든 정확히 그립니다.
  • 사운드 — ElevenLabs 음악 · 효과음 큐를 장면 타임라인에 믹스.
  • 출력 — MP4 1920×1080 / 1080×1920, 그리고 영상 없이 도는 웹 플레이어(13분 ≈ 10MB).
  • 다국어 — 번역 파일 · 폰트 교체 · RTL. 같은 장면 파일 그대로.
cd canvas-film/examples/hello
node ../../scripts/render.mjs h --scene dawn --stills 3,8
python3 ../../scripts/publish.py   # → site/ (라이브 플레이어)

요구 사항: Node + Playwright Chromium, ffmpeg, Python 3. 자세한 순서는 SKILL.md.
