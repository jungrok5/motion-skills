canvas-film

장면마다 화풍이 다른 시네마틱 영상을 HTML Canvas만으로 그립니다. 같은 장면 파일로 가로와 세로 MP4를 녹화하고 웹 플레이어에서 실시간으로 재생하며, 언어 파일을 추가하면 그 언어로도 재생합니다.

  • 16:9 · 9:16
  • MP4
  • 라이브 플레이어
  • 사운드
  • 다국어

작업 흐름

입력
이야기 · 대본 · 사이트 글을 20–60초 장면으로 나누고, 장면마다 의미에 맞는 화풍 선택
장면
장면마다 HTML 파일 한 개. seek(t)로 어느 시점의 프레임이든 같은 그림
사운드
ElevenLabs 음악 · 효과음 큐를 장면 타임라인에 믹스
출력
MP4 1920×1080 · 1080×1920, 영상 파일 없이 재생하는 웹 플레이어(「한눈에 보는 성경 이야기」 13분 기준 약 10 MB)
다국어
번역 파일 · 폰트 교체 · RTL. 장면 파일은 바꾸지 않음
cd canvas-film/examples/hello
node ../../scripts/render.mjs h --scene dawn --stills 3,8
python3 ../../scripts/publish.py   # → site/ (라이브 플레이어)

요구 사항: Node + Playwright Chromium, ffmpeg, Python 3. 단계별 순서는 SKILL.md에 있습니다.
