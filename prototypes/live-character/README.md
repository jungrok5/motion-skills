# live-character (프로토타입)

코드로 그린 2.5D 반신 캐릭터가 사람처럼 숨 쉬고, 깜빡이고, 포인터를 바라보고, 머리카락을 흔들며 움직이는 리그입니다.
캐릭터 제작 스킬로 만들기 전 단계의 실험이라 아직 `SKILL.md`가 없습니다.

- 출처: [yeko_L의 X 게시물](https://x.com/yeko_L/status/2118290984924856713) → [livliv-dev/player](https://github.com/livliv-dev/player)
  (LivLiv Player, Apache-2.0). 움직임 원리(`runtime/idle.ts`, `actions.ts`, `puppet.ts`)를 연구해 벡터 캐릭터용으로 다시 구현했습니다.
  LivLiv의 캐릭터 그림은 비상업 전용이고 "다른 캐릭터 생성에 사용 금지"라 쓰지 않았습니다. 하루는 여기서 새로 그린 캐릭터입니다.

## 돌려 보기

```bash
cd prototypes/live-character
python3 -m http.server 8765            # http://localhost:8765/ 을 연다
node scripts/render.mjs demo.mp4       # 18.5초 데모를 MP4로 (Playwright + ffmpeg)
node scripts/poses.mjs poses.png       # 극단 포즈 시트: 좌우·상하·기울기 끝, 표정, 입 모양
node scripts/shots.mjs out 1.5 3 6     # 데모의 그 시각 스틸
node scripts/build-single.mjs one.html # 모듈을 한 파일로 (Artifact 등)
```

## 파일

| 파일 | 역할 |
|---|---|
| `rig.js` | 캐릭터와 무관한 엔진: 파라미터, 자연스러운 idle, 비교용 사인파 idle, 동작(끄덕·도리도리·갸웃·깡총·깜짝·수줍·쓰담), 한글 음절 립싱크, 2.5D 변형기, 머리카락 스프링, 120 Hz 고정 스텝 시뮬레이션 |
| `draw.js` | 경로의 모든 점(제어점 포함)을 변형기에 통과시켜 그리는 헬퍼 |
| `haru.js` | 캐릭터 하나: 앵커(머리 타원, 목, 턱), 리그 수치, 머리카락 가닥 정의, 그리기 순서와 깊이 |
| `index.html` | 무대 + 조작(표정, 동작, 말하기, 자연/사인파 비교, 변형 격자). `window.live.renderAt(t)`는 결정적 |
| `scripts/` | 렌더 · 포즈 시트 · 스틸 · 단일 파일 빌드 |

## 자연스러움의 레시피 (rig.js 머리 주석에 수치)

1. **2.5D 머리**: 머리를 포물면 위에 올리고 부위마다 깊이(뒷머리 −0.35, 얼굴 0, 눈 0.04, 코 0.18, 앞머리 0.26). 고개를 돌리면 시차.
   깊이는 두개골 가장자리에서 0으로 줄어 실루엣이 찢어지지 않음. 회전은 ±15°쯤에서 멈춤 (2D는 그 이상에서 납작함이 드러남).
2. **스프링 추종**: 목표는 값 노이즈(반복 없음) → 0.12초 이징 → 감쇠 스프링. 눈이 먼저, 고개는 살짝 넘침, 몸은 0.25초 늦게.
3. **불규칙한 생리 리듬**: 숨 3.2–4.6초(들숨 40%·날숨 48%·멈춤), 깜빡임은 75 ms 감고 120 ms 뜸, 18%는 이중 깜빡임, 큰 시선 이동엔 깜빡임.
4. **idle 동작**: 10–20초마다 곁눈질·둘러보기·흔들기·생각·내려보기·콧노래 중 하나(무작위 좌우 반전).
5. **주의(attend)**: 포인터가 오면 눈썹이 들리고 턱이 살짝, 멈춰 있으면 2.2초 뒤 시청자에게 돌아오며 끄덕.
6. **머리카락**: 가닥마다 2단 스프링(뿌리 강하고 끝 느슨), 뿌리 가속도로 던져지고, 기울이면 중력으로 늘어짐, 가닥마다 강성 ±12%.
7. **관절 한계**: 몸 회전 ±12°, 기울기 ±5°, 시선은 타원 안 (`scripts/poses.mjs`로 극단 포즈 확인).

## 스킬로 만들 때 남은 일

- 주제 → 캐릭터 브리프(성격, 머리 모양, 옷, 팔레트, 움직임 성향) → 새 캐릭터 파일을 만드는 흐름과 스캐폴드(`new-character.mjs`)
- 머리 모양 부품화(앞머리 가닥 생성기, 포니테일·트윈테일·단발 체인), 옷 부품(후드, 셔츠, 교복)
- 캐릭터마다 다른 움직임 성향(차분 / 발랄: wander, 스프링 강성, idle 동작 빈도)
- `check` 스크립트: 결정성, 극단 포즈의 찢어짐·삐져나옴 자동 검출, 정지 프레임 채점
- `docs/live-character/` 샘플 페이지, `docs/skills.json` 등록
