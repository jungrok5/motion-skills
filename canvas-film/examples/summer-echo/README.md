# 여름의 잔향 — After the Last Train

38초 길이의 독립 HTML 애니메이션. 이전 작업에서는 **여름 건널목, 지나가는 전철, 사라진 상대, 돌아보는 인물, 남은 하늘**이라는 이야기만 가져왔다. 기존 원화·리그·장면 코드·효과·카메라는 사용하지 않았다.

## 실행

```sh
node build.mjs
# 생성된 summer-echo.html을 브라우저에서 연다. 인터넷 연결 불필요.
```

분리된 소스를 개발할 때는 이 디렉터리에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 연다. 번들 빌드는 Node 표준 라이브러리만 사용한다. 실행에는 WebGL이 필요하다. 별도 SDK·CDN·API 키·모델 호출이 없다.

모바일은 세로 구도로 시작한다. 가로/세로 전환, 장면 선택, 타임라인 탐색, 전체 화면, 소리 켜기, 고정 카메라 연기 루프를 제공한다. 브라우저 자동재생 제한 때문에 소리는 사용자가 켜야 한다.

## 새 연출

| 시간 | 장면 | 연기 / 화면 |
|---|---|---|
| 0–5 | 한여름 | 해안의 높은 하늘, 타이틀과 느린 하강 |
| 5–11 | 건너편의 너 | 원경의 상대와 전경의 주인공, 무게 이동과 시선 |
| 11–13.5 | 멈춘 말 | 경고등 인서트, 교대 점멸 |
| 13.5–20 | 지나가는 시간 | 열차가 상대를 가림; 바람에 손을 들어 머리를 누름; 얼굴 클로즈업 |
| 20–22.5 | 빈자리 | 인물이 없는 반대편, 올라가는 차단기 |
| 22.5–32 | 늦은 인사 | 눈이 먼저 움직임 → 고개가 따라옴 → 멈춤 → 시선 하강 → 작은 미소 |
| 32–38 | 여름의 잔향 | 저녁빛으로 바뀌는 하늘, 멀어지는 새 |

## 파일 역할

- `story.js`: 목적·서사·샷·자막·연기 키·눈 깜빡임 시간.
- `rig.js`: 새로 작성한 WebGL 삼각형 메시, 머리 변형, 코드로 그리는 눈/입/표정, 2본 IK 팔, 120Hz 감쇠 스프링 머리카락.
- `film.js`: 별도 카메라와 세로 구도, 열차·차단기·경고등·바람·광학 효과·엔딩.
- `audio.js`: Web Audio로 만든 간단한 오리지널 음계, 바람·경고음·열차 리듬.
- `player.js`: 재생·탐색·모바일·전체 화면·고정 카메라 연기 보기.
- `assets/`: 이번에 새로 생성한 원화 2장과 독립적으로 받은 Noto 글꼴.
- `build.mjs`: 이미지·글꼴·코드를 하나의 HTML에 내장.
- `brief.template.json`: 다른 주제를 설계할 때 사용할 입력 항목.
- `art-prompts.md`: 이번 원화의 생성 프롬프트와 출처.

## 목적이나 주제를 주면 다음 작품을 만드는 순서

1. 목적과 관객의 마지막 감정을 한 문장으로 정한다.
2. 그 감정을 바꾸는 행동을 3–5개로 쓴다. 동작이 없는 설명문만으로 구성하지 않는다.
3. 샷마다 시선, 몸, 손, 표정의 선후 관계와 정지 시간을 정한다.
4. 캐릭터 원화를 머리·앞머리·뒷머리·몸처럼 겹침을 보장하는 부품으로 만든다.
5. 소스 사각형과 피벗을 맞추고 눈/입/팔/머리카락을 연결한다.
6. 고정 카메라에서 연기를 먼저 검수한 뒤 카메라와 효과를 넣는다.
7. 가로·세로, 오프라인 실행, 장면 경계, 탐색 재현성을 확인하고 HTML로 묶는다.

이 결과물은 이 제작 방식을 구현한 첫 독립 작품이다. 임의의 주제 문자열만 바꾸면 새로운 완성작이 자동 생성되는 제품은 아니다. 새 인물과 장소에는 새 원화, 리그 좌표, 샷 설계가 필요하다. 현재 카메라/레이아웃에는 이 작품의 시간값이 포함되어 있다.

## 범위와 한계

Live2D Cubism SDK를 사용하지 않는 자체 2.5D 리그다. 머리의 제한된 좌우 회전과 기울임을 표현하며, 90도 측면이나 완전한 3D 회전은 지원하지 않는다. 팔/얼굴 일부는 코드 작화이므로 원화와 질감 차이가 남는다. 걷기·립싱크·대사 녹음은 포함하지 않았다. 사운드는 합성음이며 오케스트라 녹음이 아니다. 실제 Galaxy/iPhone 하드웨어 성능을 측정하지 않았으므로 모든 기기에서 고정 FPS를 보장하지 않는다.

## 원화와 글꼴

원화 두 장은 이 작업 중 내장 이미지 생성 도구로 새로 만들었다. 영상은 프레임별 영상 생성 결과가 아니라 이 원화를 코드 리그와 합성기로 움직인 결과다. 이미지는 참조 입력 없이 생성했다. 원본 PNG를 그대로 보관하고 런타임에 부품을 샘플링한다.

Noto Sans KR / Noto Serif KR은 Google Fonts에서 별도로 받은 글꼴을 필요한 글자로 서브셋했다. SIL Open Font License는 `assets/OFL-Noto.txt`에 있다. 다른 프로젝트나 이전 애니메이션의 글꼴 파일을 복사하지 않았다.
