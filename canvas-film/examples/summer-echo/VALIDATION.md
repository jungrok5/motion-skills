# 검수 기록

## 브라우저 검수

로컬 Chromium 153 / SwiftShader에서 HTML을 file://로 열었다. 오프라인 실행 시 외부 HTTP 요청 0건, JavaScript 오류 0건이었다.

확인한 시점: 0, 2.8, 5, 11.3, 14.6, 16.8, 18.9, 20.5, 23.5, 27.6, 29.4, 35.3, 38초.

- 재생/일시정지, 타임라인 탐색, 장면 선택, 소리 켜기 검수.
- 390×844 뷰포트에서 세로 구도 자동 선택, 가로 넘침 없음.
- 일반 영상에서 24.7초 → 다른 시점 → 24.7초의 픽셀 해시 일치.
- 연기 보기에서 서로 다른 시점의 화면이 달라 실제 캐릭터 움직임이 있음을 확인.
- 팔 길이가 비정상적이던 초기 동작을 2본 IK로 수정하고, 어깨/팔꿈치 연결과 치마 경계를 시각 검수.
- 별도 한국어 글꼴을 내장해 자막 네모 표시 수정.

## 영상 출력

912프레임을 24fps로 렌더링한 38초 미리보기. H.264, 1280×720, AAC 오디오. 미리보기 오디오는 브라우저 합성음의 음계와 효과 타이밍을 바탕으로 별도로 합성했다. HTML과 오디오 파형 자체가 완전히 같지는 않다.

실제 휴대폰 하드웨어 FPS와 Safari는 측정하지 않았다. 브라우저 에뮬레이션의 레이아웃 검수와 실제 기기 성능 검수는 구분한다.
