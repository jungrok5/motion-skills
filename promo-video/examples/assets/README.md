# Example assets

Copy this folder to your project root as `assets/`. Video pages load it as `../assets/…`.

| path | what | license / source |
|---|---|---|
| `fonts/Pretendard-Variable.woff2` | Pretendard 1.309, variable weight 100–900 (Korean + Latin). © 2023 Kil Hyung-jin | SIL Open Font License 1.1 (https://openfontlicense.org) |
| `fg-logo.png` | the "FG" mark of Fortimove Global, the client the two examples were made for | used here with the client's permission as an example only; replace with your own logo |
| `sfx/stamp.mp3`, `sfx/slap.mp3`, `sfx/typing.mp3` | rubber stamp, paper slap, phone typing — generated with ElevenLabs Sound Effects (prompts in `references/SOUND.md`) | generated for this project; regenerate your own for commercial use under your ElevenLabs plan |

The examples' `audio/narration.mp3` takes were generated with ElevenLabs (voice "Dahye", Eleven v4) for the same client.
