설명 읽기용어집

M.2 SSD 한 장을 열어 NAND 다이 네 개와 블록 하나까지 들어간다. NAND는 페이지 단위로 쓰고 블록 단위로만 지우기 때문에 SSD 안에서는 GC가 계속 돈다. 같은 다이에서 지우기가 도는 동안 그 다이로 온 읽기는 끝날 때까지 기다리고, 평소 0.08ms인 읽기가 3ms를 넘는다. 화면의 시간 수치는 예시다.

NAND 패키지 안에는 다이가 여러 장 쌓여 있다. 화면은 다이 네 장을 꺼내 옆으로 펼치고, 다이마다 타임라인 한 줄을 붙인다. 컨트롤러는 쓰기와 읽기를 여러 다이에 나눠 보내고, 각 다이는 자기 일을 따로 처리한다.

다이 한 장이 한 번에 하는 작업의 길이는 종류마다 크게 다르다. 예시 수치로 읽기 0.08ms, 프로그램(쓰기) 0.7ms, 지우기 3.5ms다.

다이 2의 블록 두 개로 들어간다. NAND는 이미 쓴 페이지를 그 자리에서 고쳐 쓰지 못한다. 데이터가 바뀌면 새 페이지에 쓰고, 옛 페이지는 무효로 표시한다.

빈 페이지는 블록 전체를 지워야 다시 생긴다. 그래서 GC는 블록 A에 남은 유효 페이지 10개를 블록 B로 옮겨 쓴 뒤(프로그램 10번) 블록 A 전체를 지운다. 쓰기는 페이지 단위, 지우기는 블록 단위다.

다시 다이 네 개의 타임라인이다. 다이 2가 GC 지우기(3.5ms)를 시작한 직후, 다이 1과 다이 2에 읽기가 하나씩 온다. 다이 1의 읽기는 0.08ms에 끝난다. 다이 2의 읽기는 지우기가 끝날 때까지 기다린 뒤에야 시작해 약 3.2ms가 걸리고, 1ms 목표선을 넘는다.

이런 읽기가 지연 분포의 꼬리(p99)를 만든다. 대응은 지우기를 잠시 멈추고 읽기를 먼저 처리하는 erase suspend, 여유 공간(OP)을 늘려 GC 횟수 줄이기, TRIM으로 쓸모없는 페이지를 미리 알려 주기다.

용어 정리

NAND 다이
NAND 플래시 칩 한 장. 패키지 하나에 여러 장이 쌓여 있고, 다이마다 따로 읽고 쓴다.
페이지
NAND에 쓰고 읽는 단위. 이미 쓴 페이지는 지우기 전까지 다시 쓸 수 없다.
블록
페이지 여러 개를 묶은 단위. 지우기는 블록 단위로만 한다.
프로그램
빈 페이지에 데이터를 쓰는 NAND 작업. 이 영상의 예시 시간은 0.7ms.
지우기 (erase)
블록의 모든 페이지를 빈 상태로 되돌리는 작업. 이 영상의 예시 시간은 3.5ms.
GC (가비지 컬렉션)
무효 페이지가 많은 블록에서 유효 페이지를 다른 블록으로 옮기고, 그 블록을 지워 빈 블록을 만드는 SSD 내부 작업.
erase suspend
진행 중인 지우기를 잠시 멈추고 읽기를 먼저 처리한 뒤 지우기를 이어 가는 NAND 기능.
OP (오버프로비저닝)
사용자에게 보이지 않게 남겨 둔 여유 공간. 클수록 GC가 덜 자주, 덜 많이 옮긴다.
TRIM
운영체제가 지운 파일의 페이지를 SSD에 알려 주는 명령. SSD는 그 페이지를 옮기지 않아도 된다.
